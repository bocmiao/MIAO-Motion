# MIAO Motion / 喵动

免费开源、本地优先、面向零基础用户的 VRM 动漫角色实时动捕与 OBS 直播工具。

> 当前版本：v0.2.0 第一代可运行版。普通摄像头可以实时驱动 VRM 的头部、眨眼、眼神、嘴型和微笑。

## 已经能做什么

- 拖放或选择本地 VRM 0.x / 1.0 模型。
- 使用 MediaPipe Face Landmarker 实时识别人脸。
- 驱动头部俯仰/转向/侧倾、左右眨眼、眼神、张嘴和微笑。
- 一键校准当前正面姿态，动作使用帧率无关平滑。
- 自动检查模型的头部、眨眼、嘴型和视线兼容性。
- 影棚、绿幕、透明三种背景。
- 保存最后导入的模型到浏览器本地，OBS 页面可自动恢复。
- 提供无界面直播模式及 OBS 浏览器源地址。
- 摄像头画面与模型不上传服务器。

## Windows 小白启动方法

1. 安装 [Node.js 22 LTS 或更新版本](https://nodejs.org/zh-cn)。
2. 下载并解压本仓库。
3. 双击 `start-windows.bat`。
4. 浏览器打开后，点击“选择 VRM”，再点击“开启摄像头”。
5. 正对摄像头点击“正面校准”。

第一次开启动捕需要联网下载约 4 MB 的 Google Face Landmarker 模型和 MediaPipe 运行文件。之后浏览器通常会缓存它们。推理过程在本机完成。

## OBS 使用

### 推荐：浏览器来源

1. 保持 `start-windows.bat` 窗口运行。
2. 在普通页面先导入一次模型。
3. 点击“复制 OBS 浏览器源地址”。
4. OBS → 来源 → 添加“浏览器” → 粘贴地址。
5. 推荐尺寸 `1920 × 1080`，在 OBS 的“交互”窗口允许摄像头权限。

地址格式：

```text
http://127.0.0.1:4173/?broadcast=1&background=transparent
```

如果 OBS 环境无法取得摄像头权限，可在普通浏览器使用“背景：绿幕”和“进入直播画面”，再用 OBS 窗口捕获配合色度键。

## 当前边界

- v0.2.0 只做脸部和头部动捕，身体、手部和音频口型留到后续版本。
- 用户需要自行准备有合法使用权的 VRM 模型。
- 首次加载 MediaPipe 资源需要联网；摄像头帧不会发送给 Google 或项目服务器。
- OBS 对摄像头权限的处理随系统和 OBS 版本不同，绿幕窗口捕获是可靠后备方案。

- 不需要账号，不包含遥测。
- 模型保存在当前浏览器的 IndexedDB 中。
- 摄像头帧仅交给当前设备上的 MediaPipe 推理。
- 建议只通过 `127.0.0.1` 启动，不要暴露到公网。
