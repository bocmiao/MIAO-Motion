# MIAO Motion / 喵动

免费开源、本地优先、面向零基础用户的实时动漫角色动捕与 OBS 直播工具。

> 当前状态：技术底座开发中。仓库现已具备可运行的 Web 原型，可开启摄像头并拖入 VRM 0.x/1.0 模型进行本地预览。

## 产品目标

- 没有模型也能选择内置角色开始体验。
- 普通摄像头即可驱动脸部、上半身和双手。
- 导入自己的 VRM 后自动检查骨骼、表情、纹理和性能。
- 五个动作完成个人校准。
- 一键创建 OBS 透明 Browser Source。
- 摄像头画面只在本机处理，不默认保存或上传。

## 当前已完成

- 中文零基础入口骨架。
- 摄像头权限、预览和关闭。
- 拖放或选择本地 `.vrm` 文件。
- Three.js + three-vrm 本地模型预览。
- 响应式基础界面与构建检查。

## 下一里程碑

1. 接入 MediaPipe Tasks Vision。
2. 驱动头部、眨眼和嘴部。
3. 建立最小模型医生。
4. 增加 OBS Browser Source 输出。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 使用当前原型

1. 点击“开启摄像头”，允许浏览器访问摄像头。
2. 点击“导入已有模型”，或把 `.vrm` 文件拖入右侧预览区。
3. 拖动旋转角色，滚轮缩放。

当前摄像头与角色预览尚未连接动作追踪，这是下一里程碑。
