换色、语音与更多输入输出

先试原创猫咪

新手教程第二步点“使用原创猫咪 · 喵小动”，等“正在准备画面…”结束后开始操作。也可导入自己的 VRM，或使用保留的 pixiv 技术示例。

轻捏人和表情

展开“换色、表情与语音嘴型”，选择材质（如毛发、衣服），点击颜色框。当前版本支持材质换色和恢复原色，不支持换发型、替换衣服网格或导出修改后的 VRM。颜色按角色保存在本机。纹理的图案仍会保留，纯黑纹理不能只靠染色变白。

表情下拉框支持自然、开心、生气、难过、放松和惊讶；本窗口内按 0–5 切换。输入框和弹窗中不会触发表情热键。这些不是系统全局热键，缺少的模型表情会禁用。

只用麦克风也能动

点“开启语音嘴型”并允许麦克风权限。讲话音量控制张嘴幅度，可用滑块调节；不录音、不回放、不上传。关闭按钮、离开页面或关闭应用会释放麦克风。语音嘴型优先于摄像头和手机嘴型；面部表情仍可叠加。

身体和手部（实验）

开启摄像头后，在高级设置勾选“身体与手部”。使用打包在本机的 MediaPipe 模型，识别四肢方向及有骨骼支持的手指。追踪频率上限 10 次/秒，低配电脑可能明显降帧，届时关闭该项并选“性能优先”。请保持肩、手、腿入镜；遮挡或单摄像头深度估计不准会影响动作。猫咪示例没有独立手指。

自动画质和更新

画质选“自动调整”后，会每 5 秒统计一次帧率，连续低帧率时降低渲染清晰度，持续流畅后缓慢恢复；不会更改输出比例。高级设置中的“检查新版本”仅在点击时访问 GitHub，不会自动安装更新。

自动配置 OBS

  1. 在 OBS 的工具菜单启用 WebSocket 服务器，端口用 4455，复制服务器密码。
  2. 在喵动加载角色后，展开“自动配置 OBS”，填入密码并点击“创建绿幕场景”。密码只用于本次连接。
  3. 喵动进入绿幕模式，OBS 新增专用场景、窗口来源和色度键。回到 OBS 选择新场景预览，检查取景后再开播。不会替你开始推流，也不会修改原有场景。

支持 Windows 的窗口捕获。若找不到窗口，按提示在已创建的场景里手动选择；浏览器标题、窗口最小化和 OBS 权限差异都可能影响捕获。

原生虚拟摄像头

  1. 使用 Windows 安装版，加载角色。
  2. 点“安装摄像头组件”，完成 Windows 管理员权限确认；再点“开始虚拟摄像头输出”。
  3. 重启会议或直播软件，在摄像头列表选择 MIAO Motion Camera。
  4. 结束时点“停止”；卸载喵动之前先点“卸载摄像头组件”。

当前输出 640×360、最多 15 帧/秒，仅传角色画布，保持比例、没有透明通道。支持 64 位 DirectShow 接收端；不保证 Windows Camera/UWP 或 32 位软件可识别。若软件不支持，使用 OBS 虚拟摄像头中转。安装组件与打开实体摄像头是两件独立的操作。

手机面捕

  1. 在支持 iFacialMocap 的 iPhone/iPad 上启动应用，将手机和电脑接入同一可信局域网。
  2. 在喵动安装版输入手机的 IPv4 地址，点击“连接手机面捕”。
  3. 按页面显示的电脑 IP，在手机端设置 UDP 目标端口 49983。系统提示防火墙时仅允许你的专用网络。
  4. 看到“正在接收手机面捕”后自然转头；停止按钮关闭接收端口。中断超过半秒会回到待机动作。

只接收指定手机的动作参数，不传视频，不经过云服务。此接入目前是 iFacialMocap 文本协议，不是任意手机相机网页、VMC 或 Live Link。具体手机与会议软件仍需真机验收。
