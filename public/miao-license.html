喵小动 · 喵动原创猫咪

喵小动是喵动项目的原创角色，由项目源码中的程序生成：奶油色毛发、深青色套装、黄色徽章。几何、配色、骨骼和表情都能从源码重新生成，没有使用 pixiv 或其他第三方角色的数据。

你可以怎么改

在“换色、表情与语音嘴型”里，新版喵小动可以：

  • 换耳朵（尖耳朵 / 圆耳朵）、尾巴（长 / 短）、发型（小发簇 / 清爽）、衣服（徽章上衣 / 连帽上衣）；
  • 给毛发、衣服等部位换颜色；
  • 起一个自己的名字；
  • 点“导出我的角色 VRM”，保存成 VRM 文件，之后可以再导入喵动或其他支持 VRM 的软件。

喵小动是猫爪造型，没有独立手指；需要精细手指追踪时，请导入带完整手指骨骼的 VRM。

导出的角色归谁、怎么用

导出文件里写着：名字是你起的名字；作者仍为喵动项目（MIAO Motion contributors）；许可为 VRM 公共许可 1.0。改色、换部件、起名都不会改变作者和许可。用大白话说：

  • ✓ 可以用它直播、录视频、开会
  • ✓ 可以接打赏、带货、接广告等商业用途，个人和企业都可以
  • ✓ 可以改色、换部件、起名后发布或送给别人
  • ✓ 可以把 VRM 文件再分发，别人拿到后同样可以使用和修改
  • ✓ 不需要署名（愿意写“角色：喵动 · 喵小动”我们很开心）
  • ✗ 不能用于过度暴力、过度色情、政治或宗教用途、反社会或仇恨内容
  • ✗ 不能冒充喵动官方，或声称你是喵小动原创作者

以上是白话说明，具体以 VRM 文件内元数据和 VRM 公共许可 1.0 全文为准。角色按现状提供，不作适用性保证。

“喵小动”这个名字

“喵小动”的名称和原创形象属于喵动项目。你可以在直播和视频中使用喵小动或你改过的版本，也可以给它起新名字；但请不要用“喵动官方”“喵小动官方”等说法让人误以为你代表本项目或得到本项目背书。VRM 许可不授予“喵动 / MIAO Motion”名称和标志的所有权，详见项目的商标与资产政策（TRADEMARKS.md）。
