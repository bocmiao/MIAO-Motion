把角色接入你的平台

回到喵动 · 扩展功能 · 使用帮助

先在首页选角色，等画面出现并完成正面校准。主界面的“我要接入”可按平台显示简要步骤。平台客户端经常改版，下面的菜单位置是“通常在哪里”，以你电脑上的当前版本为准；能否开播、能否用推流码由平台对你账号的规定决定，喵动不能代办或绕过。各平台尚未全部完成真机验证。

手机 App 不能直接选择电脑上的虚拟摄像头。要在抖音、快手、视频号、小红书等平台用喵动开播，请使用平台的电脑端开播工具，或平台提供的推流码。

三条通用路线

路线适用限制
① 窗口捕获 + 抠绿幕（推荐）便携版、安装版都能用；几乎所有电脑直播软件喵动窗口不能最小化或被完全挡住
② 原生虚拟摄像头 MIAO Motion Camera（实验）仅 Windows 安装版；能选摄像头的 64 位电脑软件、会议软件640×360、最多 15 帧/秒、没有透明背景；安装组件要管理员确认
③ OBS 推流码平台给账号提供了推流地址和密钥需平台开通；密钥不能泄露

① 窗口捕获 + 抠绿幕

  1. 喵动背景切到“绿幕”，点“进入直播画面”（Esc 或双击返回）。
  2. 直播软件添加“窗口捕获”（也可能叫“窗口”“窗口采集”），选择喵动窗口。
  3. 添加“色度键/绿幕抠图”，颜色选绿色。
  4. 喵动窗口保持可见，不要最小化；单屏电脑可把两个窗口左右并排。

② 原生虚拟摄像头（安装版，实验）

  1. 让角色出现在画面中，展开“原生虚拟摄像头（Windows）”。第一次点“安装摄像头组件”，在管理员确认中点“是”。
  2. 点“开始虚拟摄像头输出”。先开始输出，再到接收软件选择摄像头。
  3. 在接收软件的摄像头列表选择 MIAO Motion Camera。没有出现或画面不动时，在接收软件里重新选择一次摄像头，或重开接收软件。

组件为 64 位 DirectShow 摄像头，存放在受保护的 Program Files 目录；32 位软件和 Windows“相机”等 UWP 应用可能看不到它，请改用路线 ① 或 OBS 中转。平时开始/停止输出不需要管理员。

卸载喵动时会请求管理员确认来注销组件；若点了“否”或没有管理员密码，程序会询问是否仍然卸载，可以继续卸载。组件留在受保护目录，不影响安全，以后可重装喵动后点“卸载摄像头组件”清理，或请管理员清理。其他 Windows 用户装的组件不会阻止你卸载。

v0.3.0-beta 的摄像头组件存在安全隐患。从 v0.3.1-beta 起升级会自动恢复已安装的组件（弹一次管理员确认）；从 v0.3.0-beta 升级时会把旧组件迁移到受保护目录。如果程序提示迁移失败或检测到旧版组件，请在“原生虚拟摄像头（Windows）”里点“卸载摄像头组件”清理。

③ OBS 推流码

  1. 在平台开播后台或电脑开播工具里查找“推流”“第三方推流”一类入口（名称以平台当前版本为准），获得服务器地址和推流密钥。没有入口说明账号未开通，喵动无法绕过。
  2. 在 OBS 用路线 ① 加入喵动（或用喵动“自动配置 OBS”）。
  3. OBS“设置 → 直播”：服务选“自定义”或平台名称，分别填入服务器地址和密钥。
  4. 先预览或录制检查，再开始推流；部分平台还要在网页或 App 里再点一次开始直播。

密钥相当于开播密码，不要截图公开、不要发给别人。喵动不读取、不保存它，也不会替你开始推流。

OBS / 录屏

  1. 喵动进入绿幕直播画面。
  2. OBS“来源”点 +，添加“窗口捕获”，选择喵动窗口；右键来源 → 滤镜 → 添加“色度键”，选绿色。
  3. 或者用喵动的“自动配置 OBS（Windows）”：在 OBS“工具 → WebSocket 服务器设置”启用服务器（端口 4455），复制密码填入喵动，点“创建绿幕场景”。会新建场景“喵动 · 绿幕角色”（重名自动加序号），包含窗口捕获和绿色抠像；不改动原有场景，也不会开始推流。
  4. 自动配置中途失败时，会删除本次新建的来源和场景；连接中断无法清理时，会列出需要你手动删除的场景名。
  5. 调整大小、背景和麦克风，录一段检查后再开播。

黑屏时确认喵动没有最小化，再在窗口捕获属性里换一种捕获方式。透明背景不保证能被窗口捕获识别，推荐绿幕。

电脑直播工具（直播姬 / 直播伴侣）

麦克风都要在直播软件里单独选择；先检查预览，再开始直播。

B站直播姬

  1. 推荐：在素材/来源区域添加窗口类素材，选择喵动窗口；当前版本有绿幕抠图时，颜色选绿色。
  2. 安装版可试：添加摄像头类素材，选择 MIAO Motion Camera。
  3. 有推流权限时：B 站通常在网页直播中心提供推流地址和密钥（以当前页面为准），可用 OBS 推流。

抖音直播伴侣

  1. 推荐：官方帮助提供“添加直播画面 → 窗口”这类窗口采集方式，选择喵动窗口，再用绿幕抠图。找不到窗口时把喵动切到前台再刷新。
  2. 安装版可试：添加摄像头类画面，选择 MIAO Motion Camera。
  3. 竖屏直播先在直播伴侣切到竖屏，喵动选 9:16。第三方推流是否开放以平台规定为准。

快手直播伴侣

  1. 推荐：用当前版本的窗口/屏幕采集入口选择喵动，再用绿幕抠图；只能采集整个屏幕时，把喵动放在固定位置再裁剪。
  2. 安装版可试：摄像头来源选择 MIAO Motion Camera。
  3. 横竖屏以直播伴侣设置为准；账号开通推流时也可用 OBS 推流。

虎牙直播

  1. 虎牙电脑开播工具通常支持添加窗口和摄像头类素材（名称以当前版本为准）。
  2. 推荐窗口捕获 + 绿幕抠图；安装版可试 MIAO Motion Camera。
  3. 账号提供推流码时，也可用 OBS 推流。

斗鱼直播

  1. 斗鱼电脑开播工具通常支持添加窗口和摄像头类素材（名称以当前版本为准）。
  2. 推荐窗口捕获 + 绿幕抠图；安装版可试 MIAO Motion Camera。
  3. 账号提供推流码时，也可用 OBS 推流。

竖屏直播：OBS 画布 1080×1920

  1. OBS →“设置”→“视频”。
  2. “基础（画布）分辨率”手动输入 1080x1920，“输出（缩放）分辨率”也填 1080x1920，帧率一般选 30，点“确定”。
  3. 喵动“输出比例”选“竖屏 9:16”，取景选半身或头像。
  4. 窗口捕获喵动，拖动红框让角色填满画面，上下留出字幕、评论和按钮的位置。
  5. 横屏直播改回 1920x1080；可用 OBS“配置文件”分别保存横屏和竖屏。

原生虚拟摄像头固定输出横向 640×360，放进竖屏会上下留边、画面偏小，竖屏优先用窗口捕获。

视频号（竖屏）

  1. 电脑端开播一般通过网页“视频号助手”（channels.weixin.qq.com）的直播功能获取推流地址和密钥，具体菜单以当前页面为准。
  2. OBS 按上面设置 1080×1920 竖屏画布，窗口捕获喵动（或用“自动配置 OBS”）。
  3. 把推流地址和密钥填入 OBS“设置 → 直播”，开始推流后回到视频号助手确认画面，再按页面提示开播。

手机微信里直接开播无法选择电脑的虚拟摄像头。直播资格和推流是否可用以微信官方规则为准。

小红书

  1. 先在小红书官方开播入口确认账号能否使用电脑开播工具或推流（以官方当前提供的入口为准）。
  2. 电脑工具有“窗口”来源时，捕获喵动绿幕窗口；有“摄像头”来源时，安装版可试 MIAO Motion Camera。
  3. 获得官方推流地址与密钥后，按 OBS 推流码路线接入，竖屏按上面设置 1080×1920。

手机 App 不能直接选择电脑的虚拟摄像头。小红书电脑端的实际兼容性仍待真机验证。

腾讯会议、钉钉、飞书、Zoom、Teams

  1. 安装版可试：喵动点“开始虚拟摄像头输出”→ 会议软件的摄像头选择 MIAO Motion Camera。看不到时在会议软件里重新选择摄像头或重开会议软件。
  2. 便携版或无法识别时：OBS 窗口捕获喵动并抠绿幕，在角色下方放一张背景 → OBS 点“启动虚拟摄像机”→ 会议里选择 OBS Virtual Camera。
  3. 虚拟摄像头只传视频，没有透明背景；麦克风在会议软件里单独选择。
  4. 会议软件的本地预览常会镜像显示自己，对方看到的方向可能不同。先请别人确认对方画面，再决定是否调整喵动的镜像。

镜像方向

“镜像动作”默认开启，像照镜子：你闭左眼、向左看、举左手、向左转头，角色都在你看来的左侧动（角色自身的右侧）。关闭后角色用自身的同侧。设置位置：高级设置与模型诊断 → 动捕设置 → 镜像动作。
