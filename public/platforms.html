把角色接入你的平台

回到喵动 · 扩展功能

先在首页选角色，等待画面出现。主界面的“我要接入”可按平台显示步骤。以下是接入路线，客户端菜单、开播权限和实际兼容性以平台为准；未完成所有平台真机验证。

先选一种连接方式

场景路线
便携版、没有管理员权限喵动绿幕窗口 → 直播软件窗口捕获；会议使用 OBS 虚拟摄像头中转。
安装版、兼容的 64 位电脑客户端实验路线：安装摄像头组件 → 开始输出 → 接收软件选择 MIAO Motion Camera。
32 位接收端、UWP 或看不到喵动摄像头使用 OBS 路线。当前未提供 32 位组件，不能承诺识别。

原生组件安装与注销需要管理员确认，普通使用喵动不需要。组件存于受保护的 Program Files 目录；卸载喵动会自动注销，取消权限确认会中止卸载，可稍后重试。公司、学校电脑按管理员策略使用。便携版不含原生摄像头与局域网手机面捕。

OBS / 录屏

  1. 进入喵动直播画面，背景选择绿幕。
  2. OBS 添加“窗口捕获”，选择喵动窗口，再添加绿色色度键。也可在喵动的“自动配置 OBS”填入本机 WebSocket 密码并创建场景。
  3. 自动配置失败会清理本次新增的来源、场景；连接中断时按提示手动清理指定名称，不会删除原有场景。
  4. 调整角色大小、背景和麦克风，先录制一段检查，再开播。

保持喵动窗口可见，不要最小化。黑屏时检查 OBS 捕获方式和窗口权限。透明网页不保证窗口捕获透明，推荐绿幕。

B站直播姬、抖音/快手直播伴侣

  1. 使用各平台官方电脑客户端，确认账号开播权限。
  2. 安装版可先试最短路线：喵动开始虚拟摄像头输出，直播软件添加摄像头并选择 MIAO Motion Camera。列表为空时重开接收软件；该路线仍为实验功能。
  3. 便携版或无法识别时，添加喵动窗口捕获并抠绿幕。若平台给账号提供了官方推流地址，也可由 OBS 推流。
  4. 单独选择麦克风，检查接收预览后再开始直播。

小红书直播

  1. 先查看账号官方开播入口，确认是否开放电脑直播工具或推流权限。
  2. 电脑工具若提供摄像头来源，可试 MIAO Motion Camera；若提供窗口来源，可捕获喵动绿幕窗口。
  3. 获得官方推流地址与密钥后，可按 OBS 路线接入。没有对应权限时，喵动不能代办或绕过。

手机 App 无法直接选择电脑的虚拟摄像头。小红书实际客户端兼容性仍待真机验证。

抖音、快手、小红书等竖屏场景

窗口捕获路线可在喵动选择 9:16，并将 OBS 画布设为 1080×1920 或同等比例；保留字幕和平台按钮空间。原生虚拟摄像头目前固定 640×360，会按比例留边；需要完整竖屏输出时优先用 OBS 窗口捕获。

腾讯会议、钉钉、飞书、Zoom、Teams

  1. 安装版可试：开始喵动虚拟摄像头输出 → 会议软件摄像头选择 MIAO Motion Camera。
  2. 无法识别或使用便携版时：OBS 窗口捕获喵动并抠绿幕，在角色下方放背景 → 启动 OBS 虚拟摄像头 → 会议里选择 OBS Virtual Camera。
  3. 虚拟摄像头只传视频，没有透明通道，麦克风仍需在会议软件单独选择。
  4. 先检查对方接收画面，再调整镜像；会议自己的本地预览可能已镜像。

平台官方推流地址

在 OBS 直播设置里填写平台提供的服务器地址和密钥。密钥属于开播凭据，不要截图公开或提交仓库；喵动不读取它。喵动不会替你开始推流。
