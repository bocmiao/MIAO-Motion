把喵动放进直播和会议

回到喵动 · 制作角色

下面是通用接入路线；各平台当前菜单、开播资质和兼容性以实际客户端为准。喵动不会代办实名认证或绕过开播限制。

OBS、B站直播姬、抖音/快手直播伴侣、虎牙、斗鱼

  1. 在喵动中导入角色、开启摄像头，点击“进入直播画面”，默认是绿幕。
  2. 在直播软件添加窗口捕获，选择喵动窗口。不要选真实摄像头预览。
  3. 添加“色度键”或“抠绿幕”效果，选择绿色；调整边缘参数，直到角色没有绿边。
  4. 直播前先录制短视频确认画面和声音。按 Esc 或双击喵动画面返回设置。

单屏幕请将喵动与直播软件左右并排，不要最小化喵动。黑屏时可在 OBS 窗口捕获属性中尝试 Windows 10（1903 及以上）方式；名称以当前版本为准。网页透明不等于窗口捕获支持透明，默认使用绿幕最稳妥。

抖音、快手、视频号：竖屏

  1. 喵动“输出比例”选择 9:16。
  2. OBS 设置 → 视频：基础画布和输出分辨率都设为 1080×1920（或设备可承受的同等比例）。
  3. 添加窗口捕获，将角色缩放到画布内；上下保留标题、字幕和平台按钮空间。
  4. 手机端不能直接选择电脑虚拟摄像头；使用平台支持的电脑直播工具或官方推流权限。

腾讯会议、钉钉、飞书、Zoom、Teams

  1. 先按上节把角色放入 OBS 场景。
  2. OBS 虚拟摄像头没有透明通道。先在 OBS 加一张背景图或纯色背景，放在角色下方；不要期待透明部分自动透出会议背景。
  3. 启动 OBS 虚拟摄像头，在会议软件选择“OBS Virtual Camera”。
  4. 麦克风仍在会议软件单独选择，虚拟摄像头只传视频。
  5. 如果对方画面左右相反，先检查会议本地预览的镜像设置，不要同时反转多个环节。

使用平台提供的推流码

  1. 登录平台官方开播页面，完成必要的实名与开播申请。
  2. 获取本次直播的服务器地址和推流密钥。
  3. 在 OBS 设置 → 直播，选择平台；没有对应项则选自定义，分别填入地址与密钥。
  4. 确认场景、音频和分辨率，先用平台预览检查，再开始正式直播。

推流密钥等同于开播凭据，不能截图公开、放入代码仓库或发到反馈群。喵动不读取也不保存推流密钥。

原生虚拟摄像头仍是研发项目；当前可用路线是 OBS 虚拟摄像头。Spout2、VMC、手机面捕和弹幕互动尚未实现。
