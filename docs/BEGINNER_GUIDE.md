# MIAO Motion 零基础使用教程

这份教程从“电脑上什么都没有”开始，适用于 v0.3.2-beta。优先使用 beta 发布页的免构建便携包或安装版，都不需要 Node.js；只有源码版才需要 Node.js 22.18+。当前为未经完整真人设备验证的测试版，不是正式稳定版。

## 1. 开始前准备

| 需要 | 说明 |
|---|---|
| Windows 11 电脑 | Windows 10 22H2 尽力兼容，但尚未真机验证 |
| 普通摄像头 | 笔记本内置或 USB 摄像头均可 |
| VRM 角色文件 | 文件名通常以 `.vrm` 结尾，支持 VRM 0.x/1.0 |
| 直播软件 | 只有直播、录屏、开会时才需要：OBS、直播姬/直播伴侣或会议软件都可以 |
| iPhone/iPad（可选） | 只有手机面捕才需要，见第 8 节；没有也完全不影响使用 |
| Node.js 22.18+ | 仅源码版需要；便携包不需要 |

不要从陌生网盘下载所谓“破解版模型”。模型能打开不代表你有直播、商业或再分发权。

## 2. 安装并启动

### 方法 A：Windows 安装版（推荐）

不知道选哪个就选安装版。打开 [测试版下载页](https://github.com/bocmiao/MIAO-Motion/releases)，在最新 beta 的 Assets 里下载 `MIAO.Motion_<版本>_x64-setup.exe`，双击按提示安装，之后从开始菜单打开。安装版功能最全，包括原生虚拟摄像头和局域网手机面捕（实验）。`.sha256` 是校验文件，`Source code` 是源代码、不是程序，普通用户都不用下载；想核对文件完整可按 [下载说明](../public/download.html) 校验同名 SHA-256。不需要 Node.js；未签名可能被系统拦截或显示“未知发布者”。无法由可信来源/哈希确认时不要运行；组织策略禁止时联系管理员。安装版与便携浏览器版的模型和设置不共享，换版需重新导入 VRM，设置可手动导入导出。

**从 v0.3.0-beta 升级必读**：v0.3.0-beta 的虚拟摄像头组件存在安全隐患。如果你在 0.3.0 里装过摄像头组件，建议先在 0.3.0 的“原生虚拟摄像头（Windows）”里点“卸载摄像头组件”，再安装新版。没来得及卸载也没关系：新版升级时会尝试把旧组件迁移到受保护目录；如果提示迁移失败或检测到旧版组件，按提示在同一位置点“卸载摄像头组件”清理。已经直接卸载 0.3.0、会议软件里还残留“MIAO Motion Camera”的，安装新版后同样点“卸载摄像头组件”即可。从 v0.3.1-beta 以后升级，已安装的组件会自动恢复（弹一次管理员确认）。

**卸载**：在 Windows“设置 → 应用”里卸载喵动。装过摄像头组件时会请求管理员确认；如果点了“否”或没有管理员密码，程序会询问是否仍然卸载，可以继续。组件留在受保护目录，不影响安全，以后可重装喵动后点“卸载摄像头组件”清理，或请管理员清理。

### 方法 B：免安装便携包（电脑不能装软件时）

1. 打开 [测试版下载页](https://github.com/bocmiao/MIAO-Motion/releases)，下载 `MIAO-Motion-portable.zip`；如果列表暂为空，表示发布构建尚未完成，不是需要注册账号。
2. 右键“全部解压缩”，确认根目录能看到 `双击启动喵动.bat`、`先看这里.txt` 和 `support`。
3. 双击 `双击启动喵动.bat`，浏览器会自动打开。
4. 保留 PowerShell 服务窗口；用完后关闭它。

包内有离线动捕资源和许可证。SHA-256 校验、未签名说明见 [下载说明](../public/download.html)。国内镜像尚无所有者凭据，未启用；不要关闭杀毒软件/智能应用控制或绕过组织策略。

### 方法 C：从源码启动

1. 从 [Node.js 官方网站](https://nodejs.org/zh-cn)下载安装 Node.js 22.18 或更新版本。
2. 打开 [MIAO Motion GitHub 仓库](https://github.com/bocmiao/MIAO-Motion)，点击 `Code` → `Download ZIP`。
3. 解压 ZIP。不要直接在压缩包预览窗口运行。
4. 双击 `start-windows.bat`。
5. 第一次会安装依赖并准备离线动捕资源，需要联网且时间较长。看到浏览器打开后，不要关闭标题含 `MIAO Motion Server` 的命令窗口。

中国大陆网络下载 npm 包较慢时，可在命令提示符中运行 `npm config set registry https://registry.npmmirror.com` 后重试。Face Landmarker 下载失败时，错误会说明如何设置 `MIAO_FACE_MODEL_URL` 镜像地址或 `MIAO_FACE_MODEL_PATH` 本地文件；无论来源如何都会校验 SHA-256。

如果双击后一闪而过：确认 Node.js 已安装，重新双击并把窗口中的完整错误文字复制到 GitHub Issue。不要关闭杀毒软件或绕过系统安全提示来解决未知文件问题。

## 3. 没有角色时制作 VRM

详细的一页式步骤见 [从零做角色](../public/create-character.html)，包括 VRoid 工程文件与 VRM 的区别、导出参数、作者/直播/商用许可与 Hub 模型选择。

1. 从 [VRoid Studio 官方中文 Steam 页面](https://store.steampowered.com/app/1486350/VRoid_Studio/?l=schinese)下载安装。
2. 新建角色，先使用默认人物也可以。
3. 调整脸型、发型、服装和颜色。
4. 导出时选择 VRM 1.0。
5. 阅读并设置模型使用条件，确认自己有直播使用权。
6. 记住导出的 `.vrm` 文件位置。

创建器右上角“完成并使用这个角色”会保存到角色库，重启后可恢复；重复保存会更新同一只。选择“不保存，返回”会恢复之前使用的角色，草稿仍留在本机。

首页可以直接选“用喵小动 / 导入我的角色 / 创建我的角色”。展开“换色、表情与语音嘴型”，可给新版喵小动换耳朵、尾巴、发型、衣服，起名并导出 VRM（作者仍为喵动项目，适用 VRM 公共许可，可直播、商用、修改再分发，见 [喵小动使用说明](../public/miao-license.html)）；其他模型只支持材质换色。没有角色时可点“先用 pixiv 示例角色试试”，它已随包保存在本机，不会联网下载或自动开启摄像头；[独立许可和来源](../public/example-license.html) 随包保留。也可以“先跳过”，学习后续相机和平台步骤。

## 4. 第一次让角色动起来

首次打开会自动显示四步教程，右上角“新手教程”可随时重开。

1. 在“准备角色”点击“选择 VRM”。
2. 等待角色出现，并查看“模型检查”。
3. 进入摄像头步骤，点击“开启摄像头”。
4. 浏览器询问权限时选择“允许”。
5. 正对镜头，等状态显示“正在驱动角色”。
6. 保持自然坐姿，点击“正面校准”。
7. 左右转头、眨眼、张嘴，确认角色方向符合习惯。

**镜像方向**：“镜像动作”默认开启，像照镜子——你闭左眼、向左看、举左手、向左转头，角色都在你看来的左侧动（也就是角色自身的右侧）。关闭后（高级设置与模型诊断 → 动捕设置 → 镜像动作），角色用自身同侧。上下方向不受影响。

动作太小或太大时，在“动捕设置”调整动作幅度。数值越大，角色反应越明显。画面抖时提高“动作平滑”；反应慢时降低。拖动画面改变机位后，按 `R` 可恢复当前头像/半身/全身取景。

## 5. 看懂模型检查

| 检查项 | 缺失时的影响 | 是否还能继续 |
|---|---|---|
| 头部骨骼 | 当前版本会阻止整套动作驱动 | 不能继续，请重新导出或更换模型 |
| 眨眼表情 | 角色不能眨眼 | 可以 |
| 嘴型表情 | 张嘴没有反应 | 可以 |
| 视线控制 | 眼神不会跟随 | 可以 |
| Humanoid 必需骨骼 | 身体或后续姿态功能可能不完整；当前只缺 Head 才阻断脸部动捕 | 按模型医生列出的骨骼回建模软件补映射 |
| 作者与许可摘要 | 信息缺失时无法确认直播、商用、署名或再分发条件 | 先联系作者或模型来源方，不要把“能打开”当成“可使用” |
| 三角面、材质 | 数量过多时可能卡顿 | 可以，先切到“性能优先” |
| 贴图和显存估算 | 大贴图可能造成显存不足或黑屏 | 可以，建议压缩贴图或换轻量模型 |

“兼容性 3/4”不是文件损坏，只表示其中一项能力不可用。缺少头部骨骼属于阻断问题，程序会阻止进入动捕步骤；缺少眨眼、嘴型或视线属于提醒。文件损坏或不是 VRM 时，程序会直接给出解析错误。

贴图显存是根据贴图宽高和常见 RGBA/mipmap 开销计算的近似值，不等于任务管理器的实际显存。第一次使用某个模型时，应以真实 FPS 和稳定性为准。

## 6. 角色库、配置档、画质和故障报告

- **性能优先**：把渲染像素比限制为 1，适合模型检查提示性能风险或集成显卡。
- **均衡**：默认档位，兼顾清晰度和性能。
- **清晰优先**：高分屏更清晰，也会增加 GPU 压力。

展开“设置与故障处理”后可以：

1. 导出画面背景、动作幅度和画质档位。
2. 从 MIAO Motion 生成的 JSON 文件恢复这些设置。
3. 恢复默认设置；不会删除已经保存的模型。
4. 删除浏览器中的模型副本；不会删除电脑上的原始 VRM。
5. 下载诊断报告，在反馈问题时作为附件提供。

每次导入的角色会进入“角色库”，可切换、重命名或删除；删除只影响浏览器副本。输入名称并保存“配置档”，会一起记录当前角色、取景、背景、镜像、画质、动作幅度、平滑和输出比例。横屏直播选择 16:9，竖屏平台选择 9:16。

开播前点击“60 秒自检”，逐项处理红色项目；黄色项目是提醒，不会强行阻止使用。本地诊断日志最多保留最近 80 条脱敏事件，可随时查看、清除或随诊断报告导出。

设置文件不包含模型、摄像头编号或画面。诊断报告包含浏览器、显卡、模型性能统计和近期错误，但不包含摄像头画面、模型内容、本机文件路径或设备编号；发送前仍建议自行打开检查。

## 7. 接入 OBS、直播平台和会议软件

三条路线：① 窗口捕获 + 抠绿幕（便携版、安装版都能用，最推荐）；② 安装版的原生虚拟摄像头 MIAO Motion Camera（实验）；③ 平台给了推流码时用 OBS 推流。各平台（B站直播姬、抖音/快手直播伴侣、视频号、小红书、虎牙、斗鱼、腾讯会议/钉钉/飞书/Zoom/Teams）的具体步骤和竖屏 1080×1920 设置见 [直播与会议软件接入指南](LIVE_PLATFORM_GUIDE.md)，程序内也有 [按平台接入页](../public/platforms.html)。手机 App 不能直接选电脑上的虚拟摄像头。

### 方法 A：绿幕窗口捕获（推荐）

1. 在普通 MIAO Motion 页面导入模型、开启摄像头并完成校准。
2. 把背景切换为“绿幕”，点击“进入直播画面”。
3. 在 OBS 添加“窗口捕获”，选择 MIAO Motion 所在的浏览器窗口。
4. 给来源添加“色度键”滤镜并选择绿色。
5. 不要最小化或完全遮挡 MIAO Motion 窗口；Chromium 可能暂停被遮挡窗口的动画。

### 方法 B：自动配置 OBS

在 OBS“工具 → WebSocket 服务器设置”启用服务器（端口 4455），复制密码；在喵动展开“自动配置 OBS（Windows）”，填入密码后点“创建绿幕场景”。OBS 会多出一个“喵动 · 绿幕角色”场景（重名自动加序号），不改动原有场景，也不会开始推流；失败时会删除本次新建的内容。

### 方法 C：原生虚拟摄像头（安装版，实验）

展开“原生虚拟摄像头（Windows）”，第一次点“安装摄像头组件”并完成管理员确认；然后**先点“开始虚拟摄像头输出”**，再在会议或直播软件里选择 MIAO Motion Camera（看不到时重新选择或重开该软件）。输出 640×360、最多 15 帧/秒、没有透明背景，仅支持 64 位软件。

### 方法 D：浏览器来源（进阶实验）

1. 用 `--enable-media-stream` 启动参数启动 OBS。
2. 添加“浏览器”来源并粘贴 MIAO Motion 提供的地址。
3. 打开该来源的“交互”窗口，在里面重新选择一次 VRM。
4. 只保留 OBS 这一页使用摄像头；关闭普通浏览器中的摄像头，避免设备占用。

地址通常类似：

```text
http://127.0.0.1:4173/?broadcast=1&background=transparent
```

OBS 内置浏览器与 Chrome/Edge 不共享模型存储，也可能不弹出摄像头授权；因此不要依赖“在普通浏览器导入后自动恢复”。广播页会在没有模型或摄像头失败时显示中文处理提示。

## 8. 手机面捕（可选，仅安装版）

用 iPhone/iPad 的面部识别驱动角色表情，比普通摄像头更细腻。**不是必需的**，普通摄像头就能用。

- 需要带 **Face ID（原深感摄像头）** 的 iPhone 或 iPad，以及付费 iOS App **iFacialMocap**（价格以 App Store 为准）。
- 安卓手机不支持；安卓用户直接用电脑摄像头即可，不推荐安装未经验证的第三方 App。
- 只有 Windows 安装版支持，便携版不支持。

步骤：

1. 手机和电脑连接**同一个 Wi-Fi**。路由器的“访客网络”或“AP 隔离/无线隔离”会拦截连接，请改连主网络或关闭隔离。
2. 把 Windows 当前网络设为“专用网络”：设置 → 网络和 Internet → 点当前网络 → “网络配置文件类型”选“专用网络”。
3. 手机打开 iFacialMocap，保持在前台、不锁屏；记下 App 上方显示的手机 IP。
4. 喵动展开“手机面捕（iFacialMocap）”，填入手机 IP，点“连接手机面捕”。程序每 2 秒自动重发连接请求。
5. 第一次连接时如弹出 Windows 防火墙提示，点“允许”。
6. 看到“正在接收手机面捕”即成功。5 秒没收到数据时，程序会提示按上面几项排查。

如果防火墙提示时点了“取消”：打开 Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙 → 点“更改设置”（需要管理员）→ 找到喵动（MIAO Motion）勾选“专用” → 确定。更多排查见 [扩展功能说明](../public/new-features.html)。

## 9. 常见问题

| 提示或现象 | 原因 | 处理 |
|---|---|---|
| 没有摄像头权限 | 浏览器拒绝了权限 | 点击地址栏左侧权限图标，改为允许后重试 |
| 摄像头被占用 | 会议软件、相机或其他页面正在使用 | 关闭占用程序，再点击开启 |
| 找不到所选摄像头 | 设备被拔出或编号变化 | 重新连接，在动捕设置中选“系统默认” |
| 未检测到人脸 | 光线暗、遮挡或人物太远 | 面向镜头、补光并靠近一些 |
| 角色不能眨眼/张嘴 | 模型缺少相应表情 | 查看模型检查；回 VRoid 重新导出或换模型 |
| 模型解析失败 | 文件损坏、不是 VRM 或导出不完整 | 重新导出 VRM 0.x/1.0，不要只修改扩展名 |
| OBS 黑屏 | 浏览器源权限或捕获方式不兼容 | 使用绿幕窗口捕获 |
| 刷新后模型没了 | 浏览器存储被清理或空间不足 | 重新导入；重要模型始终保留原文件 |
| 模型检查显示性能风险 | 面数、材质、大贴图或估算显存较高 | 先选“性能优先”；仍卡顿时回建模软件压缩模型 |
| 3D 画面停止 | 浏览器或显卡重置了 WebGL | 下载诊断报告，刷新页面；仍出现时更新显卡驱动并开启硬件加速 |
| 动捕处理失败 | 推理引擎或设备发生异常 | 程序会安全关闭摄像头；重新开启，仍失败时下载诊断报告 |
| 角色左右和想的相反 | 镜像设置与习惯不同 | 在动捕设置切换“镜像动作”；会议软件本地预览常会镜像显示，以对方看到的为准 |
| 会议软件里没有 MIAO Motion Camera | 未用安装版、未安装组件、未开始输出，或软件是 32 位/UWP | 安装组件后先开始输出，再重新选择摄像头；仍不行用 OBS 中转 |
| 手机面捕连不上 | 不在同一 Wi-Fi、路由器隔离、公用网络或防火墙拦截 | 按第 8 节逐项检查 |

## 10. 隐私和退出

- 摄像头帧、VRM 和动作推理默认留在本机。
- 程序不要求账号，也没有默认遥测。
- 点击“关闭摄像头”或关闭页面会请求浏览器释放摄像头。
- 模型副本保存在当前浏览器的 IndexedDB；清理网站数据会删除这份副本，但不会删除你的原始文件。
- “删除本地模型”只清理浏览器副本，不会操作原始 VRM 文件。
- 本地诊断事件会跨刷新保留，最多 80 条；可以在“设置与故障处理”里查看和清除。

## 11. 当前还不能做什么
