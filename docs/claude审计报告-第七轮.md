# Claude 审计报告 · 第七轮：安装版真机试用问题

> 日期：2026-09-29
> 版本：v0.3.1-beta（Windows 安装版）
> 依据：仓库所有者在 Windows 安装版上的真机试用反馈与截图，逐条对照代码查明原因
> 本轮只出报告，**未改动代码**

---

## 一、结论

真机试用暴露的问题，大多是**同一个根因**：自动测试都在普通浏览器（Chromium）里运行，从没在安装版窗口（Tauri + WebView2）里点过链接、拖过文件、保存过文件。浏览器里正常的行为到了安装版里失效，所以测试全部通过，真实用户却处处碰壁。

另外，三大目标中的第二条“通俗易懂地创造自己的角色”，在程序里**还没有真正的创建流程**，是目前离目标最远的一项。

---

## 二、真机反馈的问题与根因

### ① 引导里的“VRoid Studio（中文介绍）”点了没反应

- 现象：新手教程第 2 步，“我还没有角色，怎么制作？”里的链接点了无效。
- 根因：
  - 链接用 `target="_blank"`（新窗口打开）。安装版窗口没有处理新窗口请求，也没有安装“用系统浏览器打开网址”的能力。
  - 窗口导航还被 `src-tauri/src/lib.rs` 的 `on_navigation(trusted_origin)` 限制为只允许程序自带页面，外部网址一律被拦。
- 影响范围：`index.html` 中 **11 个 `target="_blank"` 链接在安装版里全部失效**：

  | 链接 | 位置 |
  |---|---|
  | 教我做角色（首页） | index.html:31 |
  | 打开下载页 | index.html:198 |
  | 查看平台接入步骤与限制 | index.html:213 |
  | 手机面捕“连不上怎么办” | index.html:215 |
  | VRoid Studio（中文介绍） | index.html:290 |
  | 教我一步步做自己的角色 | index.html:296 |
  | 喵小动使用说明 | index.html:298 |
  | pixiv 示例独立使用许可 | index.html:299 |
  | 打开所选平台的接入教程 | index.html:338 |
  | 查看离线零基础教程、新增功能图文教程 | index.html:339 |

### ② 教程点了选项后没有反应，让人以为没点上

- 现象：第 2 步点“使用原创猫咪 · 喵小动”等选项后，界面看起来没有变化，也不进入下一步。
- 根因：
  1. **“下一步”按钮被挤出屏幕**：引导框整体滚动（`src/style.css:251`，`overflow: auto`），底栏 `.onboarding-footer`（:291）没有固定。第 2 步内容很长，“上一步 / 下一步”在窗口外面，截图里完全看不到。
  2. **角色在引导框背后载入**：引导框是全屏遮罩弹窗，角色载入后被挡住。唯一可见的变化是顶部一行小字，从“尚未导入角色”变为“检查通过”，这行字多半也已经滚出视野。
  3. **不会自动前进**：`src/main.ts` 的 `updateOnboarding` 只更新状态，载入角色和开启摄像头成功后都要用户自己再点“下一步”。
  4. **第 2 步选项过多**：导入 VRM、VRoid 教程、教我做角色、跳过、喵小动、pixiv 示例，再加两处许可链接，一屏 7 个以上的选择，新手不知道点哪个。

### ③ 只有脸能动

- 现象：pixiv 示例角色手臂一直垂着，只有表情和头在动。
- 根因：身体与手部追踪默认关闭。开关藏在“高级设置与模型诊断 → 动捕设置 → 身体与手部（实验）”里（`index.html:112`，`#body-tracking`），而且这个选择**不保存**，每次启动都恢复为关闭。

### ④ 角色部位是纯英文

- 现象：“角色部位”下拉框显示 `Body_00_SKIN`、`HairBack_00_HAIR (Outline)`、`EyeIris_00_EYE` 等。
- 根因：`src/studio-tools.ts:129` 直接用模型文件里的材质原名作为选项。
  - VRoid 角色会列出二十多项，其中近一半是 `(Outline)` 描边，普通用户不需要单独改。
  - 喵小动的材质本来就是中文名，所以之前没有发现这个问题。

### ⑤ 首页“教我做角色”点了没反应

- 根因同 ①（index.html:31）。
- 即使能打开，`create-character.html` 也只是一页“去安装 VRoid Studio”的文字说明，并不是在程序里创建角色。

## 三、本轮新发现

### ⑥ 安装版里拖放 VRM 很可能无效（高可能性，需真机确认）

- 界面写着“把 VRM 文件拖到画面中”，`src/main.ts` 也处理了 `drop` 事件。
- 但 Tauri 2 窗口默认 `dragDropEnabled: true`，会接管 WebView2 的拖放。官方配置说明原文：“Disabling it is required to use HTML5 drag and drop on the frontend on Windows”。
- `src-tauri/tauri.conf.json` 没有关闭这个选项，所以网页自己的拖放事件大概率收不到。
- 验证方法：在安装版里把 `.vrm` 文件拖到绿色画面上，看是否载入。

### ⑦ 安装版里的“保存文件”按钮未经验证

- 涉及“导出我的角色 VRM”（`src/cat-editor.ts:40`）、“导出设置”“下载诊断报告”（`src/main.ts:278`）。
- 三者都用浏览器的 `<a download>` 方式保存。它们和 ①⑥ 属于同一类只在浏览器里测过的功能，需要在安装版里确认能否保存、会保存到哪里。

### ⑧ 程序里没有“从零创建自己的角色”的流程

| 现状 | 问题 |
|---|---|
| 捏人面板在“换色、表情与语音嘴型”折叠区中（index.html:77） | 很难找到 |
| 只有载入新版喵小动后才能用 | 其他情况下整块是灰的 |
| 耳朵、尾巴、发型、衣服 4 项，每项仅 2 种 | 选择太少 |
| 喵小动由球体和圆锥拼成（`scripts/generate-miao-avatar.mjs`），没有蒙皮 | 外观简陋，关节处会穿帮 |
| 喵小动在开发时预先生成为固定文件（`public/examples/miao-cat.vrm`） | 程序里只能切换显示或隐藏，不能调形状、大小、比例 |
| “教我做角色”指向外部软件 VRoid | 程序里没有“从零创建”的入口 |

## 四、整改建议

### P0：让安装版里的功能都能用（预计 1–2 天）

| # | 内容 | 验收标准 |
|---|---|---|
| 1 | **链接统一处理**：程序自带的说明页在程序内弹窗打开，不离开主界面，角色和摄像头不中断；外部网址只允许白名单（VRoid 官网、GitHub 下载页等），用系统默认浏览器打开。实现上可以用 Tauri 的新窗口回调或一个带白名单的 Rust 命令，不开放通用 shell 能力 | 安装版中 11 个链接都有反应；非白名单网址仍被拒绝 |
| 2 | **修复拖放**：`tauri.conf.json` 的窗口配置加上 `"dragDropEnabled": false` | 安装版中拖入 VRM 能载入 |
| 3 | **保存文件**：确认 3 个导出和下载按钮在安装版中能保存；不能则改用系统“另存为”窗口 | 安装版中能选择保存位置并成功保存 |
| 4 | **补安装版测试**：在 Windows CI 的安装版测试（`scripts/check-desktop-camera.mjs` 等）中加入“每个链接都有反应”“拖入文件能载入”“导出能保存” | 以上任一项失效时 CI 变红 |

### P1：重做新手教程和动捕体验（预计 3–5 天）

| # | 内容 | 验收标准 |
|---|---|---|
| 5 | 引导框底栏（上一步 / 下一步）固定在底部，只让中间内容滚动 | 任意窗口大小下都能看到“下一步” |
| 6 | **选完自动前进**：角色载入成功后显示大号“✓ 已载入喵小动”，约 1 秒后进入下一步；摄像头开启成功后同样处理 | 不点“下一步”也能走完主流程 |
| 7 | 引导框改为靠边的侧栏或可收起的卡片，不再遮住角色画面 | 引导过程中能看到角色载入并跟着动 |
| 8 | 第 2 步只留 3 张大卡片，与首页一致：“用喵小动”“导入我的角色”“自己创建角色”；许可链接、pixiv 示例、跳过收进“更多选项” | 第 2 步首屏不超过 3 个主要选择 |
| 9 | **全身动捕开关前移**：放到“开启摄像头”旁边，文案“全身动捕（手臂、手指）”，保存用户选择；电脑性能够时教程里推荐开启 | 用户不进高级设置也能打开，重启后保持 |
| 10 | **部位名称中文化**：按常见命名翻译（头发、刘海、后发、脸、身体皮肤、眼白、瞳孔、眼睛高光、眉毛、眼线、嘴巴、上衣、下装、鞋子、饰品等）；描边跟随主颜色，不单独列出；认不出的显示“其他部位 N”。进阶：在画面上点角色部位直接选中 | pixiv 示例角色的下拉框中没有英文和 Outline |

### P2：在程序里从零创建自己的角色（最大的一块）

11. **首页新增“创建我的角色”入口**，进入全屏的分步创建流程，每步只做一件事，右侧实时预览，可以旋转查看：

    > 起名 → 选底座 → 脸（眼睛形状和大小、瞳色、眉毛、嘴）→ 头发 / 耳朵 / 尾巴 → 衣服 → 配色（先给几套现成配色，再允许自己调）→ 开摄像头试动 → 保存到角色库 / 导出 VRM

    每一步都有“随机一个”和“上一步”；任何时候都能保存，下次接着改。
12. **把生成器搬进程序**
    - 把 `scripts/generate-miao-avatar.mjs` 的生成逻辑改成程序内模块，在用户电脑上实时生成角色。
    - 这样就能用滑块调大小、比例和颜色，不再只有两个选项。
    - 生成器只依赖 three.js 的几何体，程序里已经具备，技术上可行。
13. **美术升级**（改代码解决不了）
    - 需要一套有正经骨骼绑定（蒙皮）的基础模型，外加每类 6–10 种部件，建议请美术或社区投稿。
    - 过渡期：先把现有的拼接风格统一成 Q 版造型，每类部件扩到 4–6 种。
14. **VRoid 作为进阶路线**：保留给想做精细人形角色的用户，在程序内的说明页里用图文一步步带着做。

### 建议顺序

1. 先做 P0，所有者在安装版上复测 ①⑤⑥⑦。
2. 再做 P1，所有者按新手视角走一遍教程。
3. P2 先做创建流程和程序内生成器，美术资源并行准备。
