## 三、新发现的问题

### P1-1 点“创建我的角色”会覆盖已保存的角色，不能新建第二只（已实测复现）

- **复现步骤**
  1. 创建“布丁猫”，点“完成并使用这个角色”，保存成功。
  2. 回到首页再点“创建我的角色”：打开的是“布丁猫”的草稿，而且这份草稿绑定着角色库里的那条记录。
  3. 改名“布丁猫二号”后点完成：角色库里的“布丁猫”**被替换**成了“布丁猫二号”，只剩一条。
- **按 Esc 也会保存**：在创建器里按 Esc 等于点“完成”（`character-creator.ts` 的 `cancel` 事件调用了保存）。实测：按 Esc 后，角色库里那只被改成了“按Esc的猫”。多数人习惯把 Esc 当作“取消”。
- **想做第二只猫，只能点“放弃草稿并新建”**：这个名字听起来像要删掉已保存的角色，新手不敢点。
- **建议**
  - 从首页点“创建我的角色”时，如果当前草稿已经保存过，先问一句：“继续修改『布丁猫』”还是“新建一只猫”。
  - “放弃草稿并新建”改名为“新建一只猫”。
  - Esc 改成和“不保存，返回”一样；有未保存的修改时先询问。

### P1-2 “不保存，返回”后，放弃的修改还留在草稿里（已实测）

- 实测：把名字改成“不要的猫”后点“不保存，返回”，画面正确地恢复成了原来的角色；但再次打开创建器，名字仍是“不要的猫”。
- 发布说明写着“草稿保留”，所以这是设计如此。但按钮上写的是“不保存”，用户会以为这些修改已经丢掉了；下次打开看到放弃过的内容，会很困惑。
- **建议**：“不保存，返回”时，把草稿恢复到最后一次保存的样子。
