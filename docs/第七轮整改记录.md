## 后续 B/C 的接入边界

`src/character-spec.ts` 的底座定义具有稳定 id、animal/humanoid 家族、VRM 人形骨架约定、部件列表和比例预设。`src/character-creator.ts` 用生成器注册表选择生成器；预览、草稿、角色库、导出和摄像头流程共用。

配方独立于 glTF 节点编号，带 `version`、`baseId`、部件、脸部、比例、颜色，存入 VRM 的 `extras.miaoCharacter`。未来接入底座时添加定义和生成器，保持标准 VRM 骨架/表情约定；不改保存格式，不覆盖旧猫咪配方。未知版本或未安装底座拒绝编辑，保留原草稿。

专业美术底座、多动物和人形素材尚未提供，不把它们作为本轮已完成内容；本轮交付报告允许的程序生成 Q 版过渡方案。后续专业蒙皮模型需沿用 VRM 骨架、表情与部件许可要求。

## 验证记录

- 本机 74 项 Node 单元测试、TypeScript 与生产构建通过；浏览器回归 47 项通过，最终提交的持续集成结果见 PR。
- 本机缺少 MSVC 链接器；Rust 编译、真实 WebView2 保存与拖放、NSIS 安装生命周期在 Windows CI 执行，结果见 PR 检查。
- 摄像头/手部识别的实际帧率取决于用户硬件、入镜范围与光照；自动测试不能代表每台设备的体验。
