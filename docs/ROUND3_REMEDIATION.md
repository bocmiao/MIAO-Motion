# 第三轮报告整改对照

范围：用户要求全部整改，最终修改直接进入 main，不创建 PR；用户确认暂无国内镜像、签名证书和社区账号，先完成代码与接入说明。更新于 2026-09-29。

| 报告项 | 本轮结果 | 验证与边界 |
|---|---|---|
| 示例角色截图过早 | 等待实际角色像素，不再固定等 100 ms | 原有像素断言保留，离线模型浏览器回归 |
| “可用”与画面不同步 | 编译材质、提交首帧并等待 GPU 完成才开放直播；显示“正在准备画面…” | 人为延迟 GPU 完成的浏览器测试 |
| 下载页写死版本和哈希 | 从 GitHub Releases 选取最高完整版本、安装包/便携包及同名 SHA 文件 | 排序、缺附件、外链限制、断网回退测试 |
| 原生虚拟摄像头 | 独立 CLSID 的 MIT DirectShow 组件，安装/卸载、二进制传帧、开关和退出释放 | Windows FFmpeg 实际接收 640×360，四象限颜色和上下方向验证；64 位、15 FPS、无 alpha |
| 轻捏人 | 模型材质选择、染色、恢复原色、按角色本机保存 | 浏览器刷新与重置验证；不含服装网格/发型替换 |
| 语音嘴型 | 麦克风本地音量、阈值/灵敏度、关闭和退出释放 | 伪麦克风权限与 track 停止验证；不是语音识别 |
| 表情热键 | 0–5 表情、模型缺项禁用、输入/弹窗避让 | 窗口内快捷键，不是全局热键 |
| 自动画质 | 连续低帧率降采样，持续流畅后缓慢恢复 | 5 秒窗口、防抖与上下限；保持输出比例 |
| 更新提醒 | 主动点击查询公开版本并提示下载 | 不自动下载/安装；GitHub 不可用时给出提示 |
| 身体/手部 | 离线姿态与手部引擎，四肢和手指骨骼，失踪回到休息姿态 | 真引擎离线初始化/释放验证；实际人体准确性待真机 |
| OBS 自动配置 | 本地 v5 密码认证、新建场景/窗口来源/绿幕/画布适配 | 协议模拟验证；不替用户推流，不修改原场景；实际窗口捕获待 OBS |
| 手机面捕 | 指定局域网 IPv4、iFacialMocap UDP、包长/来源/轮询限制、停止释放 | 页面 IPC 模拟验证；真实 iPhone 待验收 |
| 原创角色 | 程序化原创猫咪“喵小动”，完整基础骨架与脸部表情 | 真实 VRM 导入兼容性 4/4，截图；独立资产条款，无独立手指 |
| 国内镜像、代码签名、社区 | 按用户确认保持未配置，交付完整接入说明 | 不编造地址、证书或账号；见 DISTRIBUTION_SETUP |
| 真机/新手试用、教程 | 已提供真实界面截图与离线图文教程、设备验收清单 | 真实相机/手机/会议软件/长时间运行及新手试用仍需安排；无真人视频 |

## 交付方式

仅用临时验证分支运行 Windows/Linux 检查，验证后快进 main，不创建 PR。既有发布工作流在 main 检查全部通过后发布 v0.3.0-beta，保留旧版本。

本版是范围明确的 beta 实现，不将自动化模拟等同于真实外设验证，不将材质换色包装为完整换装系统。
