# 项目现状（第二轮审计后）

更新：2026-09-28。当前是 **v0.2.2 脸部动捕测试版**（在 v0.2.1 修复基础上加入离线示例），不是完整 v1.0，也不是“所有独立工作已做完”。逐项修复和证据见 [第二轮整改记录](CLAUDE_ROUND2_REMEDIATION.md)。

## 已实现

- VRM 0.x/1.0 导入、骨架/表情/许可/性能检查，头部、眨眼、眼神、嘴型和微笑驱动；正面校准、镜像、平滑、待机姿态。
- 摄像头选择、并发保护、断开提示、失败重建和停止释放；模型异步代次保护。
- IndexedDB v4 多模型/配置档、同文件去重、旧库迁移清理、重命名/删除/重新载入、缩略图与最近恢复。
- 无模型/无摄像头可跳过的四步引导；离线角色制作、平台接入和帮助页。已加入允许再分发的 pixiv 官方技术示例，一键本地加载；来源、固定哈希与独立许可随包保留。
- 绿幕推荐路径、透明网页画面、完整可见的直播舞台、三个取景与横竖屏比例；实验 OBS 地址在桌面版隐藏。
- Windows Tauri 壳、本地摄像头权限处理、免 Node.js TCP 便携服务器、中文双击入口、包/哈希/预发布工作流。
- 本地推理与离线资源、脱敏日志、自检、设置备份、WebGL 恢复、MPL-2.0 与资产政策。

## 自动化能说明什么

Node 使用真实 Three.js/three-vrm 合成骨骼和 IndexedDB 行为；浏览器测试检查可见像素、透明 alpha、取景/舞台边界、引导、加载竞态、识别器崩溃重试、断开的 track 和开发模式 CSS，不再仅检查 DOM 或源码字符串。

Windows CI 新增普通用户解压启动、中断下载后存活、重复启动和静默安装/启动窗口/卸载。实际结果以 [验证记录](VALIDATION_STATUS.md) 的运行号为准，脚本存在不等于通过。

## 尚未实现，仍有独立代码工作

- 原生虚拟摄像头：只有隔离 Windows API 能力探针；MediaSource、传帧、设备生命周期与应用开关均未完成。
- 身体/手部/手指、麦克风口型、表情快捷键、键鼠姿态、VMC/iPhone。
- OBS WebSocket 自动配置、Spout2、可承诺的原生透明捕获。
- 轻捏人、内置角色目录、浏览器与桌面模型迁移、自动更新。
- 原生崩溃捕获与原子文件存储、自动画质降级、跨平台和多语言。

这些不是“缺真机所以不能做”。本轮修的是第二轮 17 项任务和相关细节，不以此替代完整路线图。
