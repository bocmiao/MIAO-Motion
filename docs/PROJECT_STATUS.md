# 项目现状审计

> 审计日期：2026-09-28  
> 审计基线：v0.2.1 候选版  
> 原则：代码存在不等于真机通过；规划存在不等于功能完成。

## 1. 已完成

### 产品和开源基础

- 产品定位、目标用户、竞品、版本路线、风险和验收门槛已经成文。
- 采用 MPL-2.0；第三方依赖、模型资产和商标边界已说明。
- README、贡献指南、安全策略、更新日志、Issue 表单、PR 模板和 Dependabot 已建立。

### 当前可运行功能

- VRM 0.x/1.0 文件选择与拖放导入。
- Three.js + three-vrm 角色渲染、相机旋转，以及头像/半身/全身取景预设。
- MediaPipe Face Landmarker 驱动头部、左右眨眼、眼神、张嘴和微笑。
- 相对四元数正面校准、帧率无关平滑、统一镜像开关、动作幅度调整和人脸丢失回正。
- 骨骼型/表情型 LookAt、自然手臂休息姿势、无人脸时呼吸和自动眨眼。
- 摄像头枚举、选择、切换、释放和常见错误中文提示。
- 模型检查：头部、眨眼、嘴型、视线、三角面、材质、贴图尺寸、几何内存和贴图显存估算；区分提醒、阻断与性能风险。
- 影棚、绿幕、透明背景；普通预览和无界面直播画面。
- 绿幕窗口捕获为推荐路径；OBS 浏览器源为带错误浮层和导入入口的实验路径。
- 最近一个模型以 Blob 存入 IndexedDB v2，并提供 v1 迁移；摄像头、背景、镜像、幅度和引导状态本地保存。
- 支持性能优先/均衡/清晰优先画质、设置导入导出、恢复默认和删除本地模型副本。
- 可下载脱敏诊断报告；WebGL 丢失、模型结构/内存问题和动捕帧异常提供细分提示与安全停止。
- MediaPipe JavaScript 按需加载；WASM 和模型在构建时校验并进入本地运行包；下载支持镜像、本地文件、超时和重试。
- CI 构建免 Node.js Windows 便携 ZIP、SHA-256 与完整许可证目录，并在 Windows runner 上实际启动内置服务器检查首页、帮助和许可证。

### 小白体验

- 首次启动自动出现四步引导。
- 无模型用户可从应用内进入 VRoid Studio 制作路径。
- 每一步显示是否具备继续条件，不能在未导入模型、未开摄像头时误跳过关键步骤。
- 新手教程可随时重开；关闭不代表完成，完成后才停止自动弹出。
- 高级设置默认折叠，应用内置离线教程。
- 零基础文档覆盖便携包/源码安装、制作模型、摄像头、校准、OBS、国内直播软件、会议软件、常见错误和隐私。

### 自动验证

- 细粒度动作求解、MToon/morph 指标、设置、脱敏、生命周期、存储迁移、启动器、离线资源和 DOM 契约测试。
- JavaScript `checkJs`、TypeScript 类型检查、声明导出一致性、Vite 生产构建、Playwright 冒烟、依赖审计和 Linux/Windows GitHub Actions。

## 2. 部分完成

| 能力 | 已有 | 缺口 |
|---|---|---|
| 模型医生 | 4 项核心能力、性能统计、估算显存和问题分级 | 还没有全量 Humanoid 骨骼检查；风险阈值尚未用真实低/中/高配设备校准 |
| 模型存储 | 自动恢复或删除最近一个模型 | 还不是可选择、重命名、带缩略图的多模型库 |
| OBS | 推荐绿幕窗口捕获；实验浏览器源有状态浮层与交互导入 | 未真机验证；没有自动创建来源、Spout2 或原生透明窗口 |
| 离线运行 | 构建产物含 WASM/模型；CI 产出 Node-free 便携 ZIP，并在 Windows runner 启动内置服务器 | 便携包尚未在干净 Windows 用户桌面双击验证；正式 Release/国内镜像未建立 |
| 错误处理 | 文件结构/内存、摄像头、离线引擎、WebGL 丢失和帧异常可解释；可导出脱敏报告 | WebGL 首次初始化失败只能显示静态错误；报告未跨崩溃持久保存 |
| 配置档 | 背景、幅度和画质可导入/导出并恢复默认 | 还没有可命名的多配置档，也未绑定模型、机位和输出分辨率 |
| 无障碍 | 中文语义、键盘按钮、状态播报、原生 dialog | 尚未经过读屏软件和完整键盘路径人工审计 |
| 性能 | MediaPipe 延迟加载、脸部模式限频、三档渲染质量和模型复杂度提醒 | 没有真实硬件 FPS、延迟、内存和长时间数据 |

## 4. 现在还能做得更好的地方

按收益和风险排序：

1. **先完成真实硬件 Gate A**：验证头部轴、左右眼、摄像头释放和最低 15 FPS。这决定 solver 是否正确，是进入桌面封装前最重要的证据。
2. **建立合法测试模型集**：至少 5 个 VRM，覆盖 0.x/1.0、分离/合并眨眼、有无 LookAt；不能把无授权模型提交仓库。
3. **做 Tauri 最小桌面包**：Gate A 通过后只封装现有功能，先实现离线安装、文件目录和干净机启动，不同时加入身体追踪。
4. **扩大浏览器端到端样本**：已有最小 Playwright 冒烟；取得合法测试 VRM 和伪摄像头素材后补模型导入、动捕、停止全部 track 和截图断言。
5. **完成多模型库**：在确认 IndexedDB 对真实大模型稳定后，再加入选择、重命名和缩略图，避免提前设计不可验证的迁移。
6. **拆分 `main.ts`**：当桌面壳或身体追踪开始进入主线时，再按 Capture/Tracking/Avatar/Broadcast 拆分。当前提前拆只会增加文件跳转。

## 5. 当前最佳下一步

在没有真机期间，代码可以继续做桌面封装准备和多模型库，但模型医生的风险阈值不能标记为“已验证”，也不应开始身体/手部或宣称 v0.2.1 发布。取得一台 Windows 设备或招募一名志愿测试者后，按 [`ACCEPTANCE.md`](ACCEPTANCE.md) 第 1 节执行，失败项优先于新功能。
