# 项目现状（第五轮整改后 · v0.3.1-beta）

更新：2026-09-29。当前代码为 **v0.3.1-beta**，包含第四、五轮全部整改；旧 v0.3.0-beta 的虚拟摄像头组件有安全隐患，应升级。整改明细见 [第五轮整改记录](ROUND5_REMEDIATION.md)，三大目标的达成情况与缺口见 [目标评估](claude审计报告-第六轮-目标评估.md)。安装版真机试用发现的问题与整改计划见 [第七轮审计报告](claude审计报告-第七轮.md)。第七轮整改的复核结果与遗留问题见 [第八轮审计报告](claude审计报告-第八轮.md)。

## 已实现

- 原有 VRM 0.x / 1.0、面部动捕、校准、模型库、取景、背景、配置、自检、脱敏诊断与离线运行。
- 等首帧完成后才提示可用；慢机器显示“正在准备画面…”，浏览器测试等待实际角色像素。
- 原创程序化猫咪“喵小动”，可重新生成；保留 pixiv 技术示例及独立许可。
- 轻捏人的材质换色与恢复、按角色保存；新版喵小动换部件、起名与导出；窗口内 0–5 表情热键；本地麦克风音量驱动嘴型。
- 自动画质调节、主动检查更新；下载页从已发布完整附件选取版本和同名校验文件。
- 可选离线身体和手部识别，低频驱动四肢和模型支持的手指。
- OBS WebSocket v5 认证、新建专用窗口场景、绿幕滤镜和适配画布。
- Windows 安装版内置可安装/卸载的 DirectShow 摄像头组件（受保护目录部署），用于实验性输出角色帧，实际链路由安装版收帧测试验证，会议软件兼容性仍待验收。卸载时注销失败可选择继续卸载，不会卡住；升级会自动恢复组件；启动时会提示清理 v0.3.0 旧组件。
- 统一镜像约定（`src/mirror.mjs`）：开启镜像即照镜子，脸、视线、头、身体、手、手机面捕同侧。
- 导出的 VRM 通过 glTF 校验（0 错误）；OBS 自动配置失败会回滚本次创建的内容；身体识别线程有看门狗。
- Windows 安装版接收指定局域网手机的 iFacialMocap 动作参数。
- 新功能图文教程、分发镜像/签名/社区接入说明、自动化测试。

## 本版边界

原生摄像头当前是 64 位 DirectShow、640×360、最多 15 FPS、无 alpha；便携浏览器版使用 OBS 中转。手机只实现 iFacialMocap 文本协议。身体/手部识别属于实验功能。新版喵小动可切换预置耳朵、尾巴、发型、衣服并起名导出 VRM；其他角色不支持换部件和导出。表情热键仅当前窗口有效。更新检查不自动下载安装。

这些功能已有代码或自动化证据，但没有把它们等同于所有物理设备和直播/会议软件都兼容。详细情况见 [验证状态](VALIDATION_STATUS.md)。
