## 已知非阻断项

- Three.js 与 three-vrm 所在的首屏脚本压缩前约 785 kB，Vite 会给出 500 kB 提示。MediaPipe 已拆为按需加载的独立块；是否继续拆渲染器要等首屏和桌面包数据，不为消除提示提前增加加载状态与分包配置。

## 必须等待真实 Windows 环境

- Windows 10 22H2、Windows 11 的用户桌面启动与浏览器权限（Windows CI 已验证无界面服务可启动和提供静态文件）。
- 笔记本内置摄像头、USB 摄像头和 OBS Virtual Camera。
- NVIDIA、AMD、Intel 集显的 WebGL/MediaPipe 差异。
- 720p/1080p 的实际 FPS、端到端延迟、CPU/GPU 和内存。
- 连续运行 60 分钟及 2 小时时的稳定性和资源增长。
- 摄像头停止后 Windows 隐私指示是否在 1 秒内熄灭。
