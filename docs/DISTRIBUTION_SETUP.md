# 镜像、签名、社区与真机验收接入

本轮用户确认暂无镜像账号、代码签名证书和社区账号。下面是实际接入步骤；当前版本不宣称已经签名或具备国内镜像。

## 国内下载镜像

1. 项目所有者开通国内对象存储/静态下载服务（例如 OSS/COS），提供可公开下载的 HTTPS 域名与独立发布账号。不要把上传密钥写进仓库。
2. 从已通过 CI 的同一个 GitHub Release 下载安装 EXE、便携 ZIP 和各自 `.sha256`。计算 SHA-256，确认一致后原样上传到按标签命名的只读目录，例如 `/v0.3.1-beta/`；不要重新打包 ZIP。
3. 从国内网络重新下载镜像文件并核对校验值，再在 `public/download.html` 增加指向该版本目录的镜像链接，保留 GitHub 官方来源。镜像故障时仍应能访问 GitHub 列表。
4. 后续自动同步应在 `publish-beta` 成功后执行；使用 GitHub Environment 保存最小权限凭据，只允许上传发布目录。程序和校验文件全部上传完成后再更新“最新版本”入口，禁止覆盖旧版附件。

当前下载页通过 GitHub Release API 选择附件与校验文件齐全的最高版本（包含 beta）。版本号、文件名和校验文件链接不再手工写死；离线/限流时仍提供官方下载列表。

## Windows Authenticode 签名

1. 由项目所有者取得受信任的代码签名证书或开通可信签名服务。GitHub Actions 临时测试自签证书不能解决用户电脑的发布者信任问题。
2. 在隔离 Windows 签名环境安装签名工具和证书，使用 Tauri 官方 Windows 签名配置的 `certificateThumbprint`、`digestAlgorithm`、`timestampUrl`，或证书服务的 `signCommand`；通过构建用的额外 Tauri 配置传入，私钥不进入 Git。
3. 本项目新增原生组件：先运行 `scripts/build-native-camera.ps1`，再签 `src-tauri/camera/` 中的 `softcam.dll`、`camera-register.exe`；随后运行 `npm run tauri -- build` 并传入签名配置，让 Tauri 签主程序、卸载器和最终 NSIS 安装 EXE。此时不要再运行 `npm run desktop:build`，它的前置步骤会重建并覆盖已签的组件。只签最外层 EXE 不能覆盖单独弹 UAC 的注册程序。
4. 对每个产物执行 `Get-AuthenticodeSignature` 检查 `Status=Valid` 和预期发布者；在未安装开发证书的干净 Windows 上复核。**签名完成后**重新计算 SHA-256，最后发布和同步镜像。

Tauri 官方说明：<https://v2.tauri.app/distribute/sign/windows/>。当前没有证书，CI 保持明确标注的未签名测试版。

## 社区渠道

所有者创建 QQ 群/B站账号后，提供正式公开链接、管理员和维护方式。在离线帮助页与 README 增加链接即可；不要填虚构群号、私人手机号或未经允许的联系方式。可先通过 GitHub Issues 收集可复现问题，避免上传面部视频或他人 VRM。

## 真机验收表

至少记录 Windows 版本、GPU、摄像头、接收软件版本、安装版/便携版及测试结果，不能用 CI 的虚拟摄像头帧代替真人验收。

| 场景 | 通过条件 |
| --- | --- |
| 新手首次安装 | 不安装 Node.js；原创猫咪加载、准备提示、摄像头授权、校准均完成 |
| 摄像头与麦克风 | 权限拒绝可恢复；停止、关闭、拔线后设备释放；麦克风无回声 |
| OBS/直播姬 | 横竖屏不裁头；绿幕无控制面板；OBS 自动配置只增加“喵动 · 绿幕角色”新场景 |
| 直播伴侣/视频号/小红书/虎牙/斗鱼/会议 | 按 [接入指南](LIVE_PLATFORM_GUIDE.md) 核对实际菜单名，记录窗口捕获与 MIAO Motion Camera 是否可用 |
| 原生输出 | UAC 安装后接收软件识别；画面、颜色、方向正确；停止/重开和卸载成功 |
| 组件卸载与升级 | 卸载时管理员确认点“否”可选择继续卸载；0.3.1 之后升级自动恢复组件；从 v0.3.0-beta 升级迁移旧组件，失败时提示清理 |
| 手机面捕 | Face ID iPhone/iPad + iFacialMocap 连接；公用网络/防火墙取消/AP 隔离时 5 秒内出现排查提示；断网待机；停止关闭端口；不同手机被忽略 |
| 身体手部 | 正对/侧身/遮挡、镜像、VRM 0/1、缺手指骨骼均检查，无长期错误姿势 |
| 低配电脑 | 首帧提示真实；自动画质不会频繁来回跳；关闭身体追踪后可恢复 |
| 零基础试用 | 邀请至少 3 位新用户独立完成“角色 → 摄像头/语音 → 接收软件”，记录卡点 |
