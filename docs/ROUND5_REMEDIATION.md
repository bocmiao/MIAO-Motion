## 需要仓库所有者在 GitHub 网页操作

代码无法修改已发布的 v0.3.0-beta。建议：

1. 编辑 v0.3.0-beta 的 Release 正文，在最上方加：
   > ⚠️ 本版本的虚拟摄像头组件存在安全隐患，请改用 v0.3.1-beta 或更新版本。装过组件的用户请先在本版本“原生虚拟摄像头（Windows）”中点“卸载摄像头组件”，再安装新版。
2. 该版本安装包的 `.sha256` 文件里写的文件名带空格（`MIAO Motion_…`），与附件名不一致。可重新上传一份文件名为 `MIAO.Motion_0.3.0_x64-setup.exe` 的校验文件（哈希值不变），或直接删除该版本的安装包附件。

## 仍需真机确认

`SOURCE_LEFT_IS_SUBJECT_LEFT` 的默认方向（同时闭左眼、举左手、向左转头看角色是否同侧）；手机头部方向；UAC 拒绝、标准用户、多用户、从 v0.3.0-beta 升级的真实表现；虚拟摄像头在各会议和直播软件中的可见性。
