依据用户在对话中贴出的第四轮审计内容实施。外部容器中的完整报告路径不在本工作区，未声称读取该文件。所有代码直接进入 main，不创建 PR。既有 v0.3.0-beta 是历史产物，不含 main 后续修复，未替换已发布的程序。

## 故障与验收

| 问题 | 修改 | 验证范围 |
|---|---|---|
| iFacialMocap 下划线通道丢失 | 识别官方 _L/_R 名称并转为内部 Left/Right，处理数值、头部与包长边界 | 官方开发者页完整报文固定为 fixture；验证眨眼、微笑、视线、张嘴通道 |

| VRM 0.x 二次翻转 | 世界方向只通过归一化骨骼父变换转换一次 | VRM 0.x/1.0 实际 raw 骨骼世界方向点积断言，两种镜像设置均覆盖 |
| 身体左右相反 | 镜像时统一交换目标侧并映射图像横轴 | 同一官方姿态数据验证两侧实际手臂方向 |
| 身体测试假通过 | 必须达到后台引擎 ready 并处理至少一帧 | 独立测试实际运行姿态/双手识别，不以初始文案通过 |
| 身体阻塞画面 | 独立 Worker，单帧在途，按负载降低识别频率 | 真推理期间主线程计时器仍运行；身体开启时画质不因 CPU 推理持续下降 |
| 摄像头全局加载可写 DLL | 注册助手嵌入构建时 DLL，部署到 Program Files 的受保护目录；拒绝重解析点和不可信所有者 | Windows CI 验证注册路径、目录/文件 ACL；不在用户电脑安装 |
| 卸载残留与等待卡界面 | NSIS 卸载钩子注销固定键；取消权限时中止卸载；Rust 后台等待真实退出码 | Windows CI 执行安装、注册、输出、卸载、检查注册键移除；无权限提示由 UI 显示 |
| 原生链路缺证据 | 安装版 WebView2 加载角色并换衣服颜色，经 Tauri 和 DirectShow 接收实际帧 | 独立组件四色测试与真实应用颜色变化测试分开；不替代会议软件验收 |
| 页面策略阻断原生传帧 | 页面 CSP 与 Tauri 配置共同允许固定本地 IPC 地址，避免退回 JSON 后拒收二进制帧 | 浏览器实际执行二进制请求，安装版端到端收帧继续验证 |
| 准备画面超时 | 只累计页面可见期间的 GPU 等待 | 模拟隐藏超过 65 秒，恢复后仍可完成真实 GPU 首帧 |
| OBS 失败留场景 | 只回滚本次创建的来源与场景；断线时列出残留名称 | 注入配置中途失败，检查删除请求与本次创建名称一致 |
| 发布校验文件名不符 | 上传前统一无空格文件名，再写 SHA-256 | 文件改名与校验内容一致的回归测试；CI 用标准 sha256sum -c |

| 首页、平台和文档矛盾 | 首页三入口，按平台向导，补小红书与原生摄像头直连路线 | 浏览器操作与文档链接检查；统一便携/安装版边界 |

## 验证边界

手机报文来自 [iFacialMocap 官方开发者说明](https://ifacialmocap.jimdofree.com/for-developer/)。MediaPipe 测试图片来源及真实引擎输出见 [fixture 说明](../tests/fixtures/mediapipe/README.md)。人造最小 VRM 仅用于可控骨架，不以伪造手部输出冒充引擎结果。

原生摄像头、手机面捕和身体/手部仍标记实验功能。原生组件仅 64 位 DirectShow、640×360、最多 15 FPS；未提供 32 位组件。普通用户可用便携版与 OBS；原生组件的安装/注销需管理员。已安装的旧版组件须完成升级迁移或注销，不能把旧发行包当成本轮修复包。

尚须真实设备验收：iPhone/iPad、真人身体/双手、腾讯会议/钉钉/直播伴侣、小红书实际客户端、360/火绒、管理员取消及不同组织策略。不会把 CI 或模拟协议当成这些实测。

喵小动仍为程序化示例，部件选择不等于完整建模软件，其他 VRM 不支持部件替换或修改后导出。正式美术、签名、国内镜像和社区账号继续按 [外部接入说明](DISTRIBUTION_SETUP.md) 安排，未虚构已接入状态。最新执行结果见 [验证记录](VALIDATION_STATUS.md)。
