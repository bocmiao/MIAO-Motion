## 2. 当前准确定位

当前产品是 **v0.2.1 脸部动捕浏览器候选版**，已具备 VRM 导入、脸部/头部驱动、模型基础诊断、设置备份、单模型恢复、绿幕/透明网页画面、离线资源和 Node-free Windows 便携包。

它还不是计划书定义的完整 Windows 直播产品。主要缺口是桌面安装包、多模型库、许可元数据、完整配置档、身体/手部、原生透明/虚拟摄像头/Spout2、OBS 自动化、跨崩溃恢复和正式发布体系。

## 4. 文档与实现冲突

1. `PROJECT_PLAN.md` 写“三步向导”，实际和路线图均为四步。
2. 教程推荐绿幕窗口捕获，但引导最后一步仍主推复制 OBS 浏览器源地址。
3. 主计划仍安排 v0.4 身体、v0.5 直播输出；Claude 审计建议先直播可用性、后身体，尚未合并成唯一版本。
4. 当前“透明输出”只是网页背景透明，不是 Windows 原生透明窗口。
5. 当前模型医生只覆盖一组关键骨骼，不是全量 Humanoid 骨骼医生。
6. 计划书仍写桌面版确定后才加入 Playwright，但浏览器 E2E 已经落地。
7. 计划承诺独立商标政策，仓库尚无 `TRADEMARKS.md`。

## 6. 必须真人、真机或外部资源完成

这些事项不阻止代码继续开发，但不能由当前无设备环境给出真实“通过”结论：

- Windows 10/11 用户桌面双击、断网、非管理员、中文路径、安装/卸载/升级。

- OBS 30/31、窗口遮挡、浏览器来源、直播姬/直播伴侣和腾讯会议。
- 原生透明窗口、虚拟摄像头、Spout2 的黑帧、纹理泄漏和兼容性。
- 5–10 名零基础用户的 10 分钟动捕、20 分钟直播接入测试。
- 有明确再分发许可的示例 VRM、代码签名证书、国内镜像和运营渠道。
