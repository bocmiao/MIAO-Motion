# 第八轮审计整改

依据 [第八轮报告](claude审计报告-第八轮.md)，代码基线 `51cfed1`。所有修改直接提交 main，不创建 PR。

| 问题 | 修改与验收 |
|---|---|
| 原生输出拖慢页面，安装测试不稳定 | 使用独立 640×360 GPU 渲染目标，异步读取像素缓冲，移除全尺寸画布的同步缩放与读回；仅一帧在途。Rust 创建、送帧、销毁通过 spawn_blocking 在后台执行，避免占住宿主窗口事件循环；停止按钮等待组件确认，停止期间不能重复启动。安装测试单次页面查询限 5 秒，整体步骤单独限时；持续记录长任务、调度延迟和实际发送进度，保留红蓝角色像素断言。 |
| 整改未发布 | 版本升为 0.3.2；现有工作流须构建、浏览器、便携版、安装版全部成功才创建 v0.3.2-beta，附件名称与 SHA-256 一起核对。 |
| 保存并返回不进角色库 | 改为“完成并使用这个角色”，等待保存成功后关闭；已有 ID 更新同一条。浏览器验证创建、重启恢复、改名后仍只有同一条记录。单独“不保存，返回”恢复上一只或最后保存的角色，草稿保留。 |
| 帧率虚高 | 显示成功发送间隔的平滑实测帧率；调速同时计入同步捕获成本与 GPU/转换/IPC 总时长，低于 1 FPS 不再虚报为 1。慢速 IPC 测试验证实际数字与输出像素。 |
| 创建后引导中断 | 记住是否从引导进入，完成后返回摄像头步骤；放弃时回到选角色步骤。 |
| 部位名称与配色矛盾、重名 | 改用“毛发”“衣服”“配饰”等名称；兼容旧模型名；同类材质加序号，补连衣裙、手套、袜子、帽子。 |
| 身体失败后设置仍开启 | 失败关闭通过相同 change 事件同步主界面、引导勾选与持久设置；故障注入测试验证。 |
| 另存为可能躲在主窗口后 | rfd 保存窗口绑定调用它的 Tauri 主窗口；安装版继续操作真实系统保存与取消窗口。 |
| 头骨骼缩放兼容性风险 | 头部比例烘焙到顶点、形变与锚点位置，Humanoid 骨骼保持单位缩放；四组比例/部件组合通过 glTF Validator。VSeeFace/cluster 等软件尚未真机验证。 |
| 稍后再说反复出现 | 主动关闭或稍后再说记录已处理，可通过“新手教程”再次打开。 |
| 文档过时 | 更新入口文案、创建保存行为、当前状态、发布说明和版本；历史审计与旧版记录保留原日期。 |
| 专业美术 | 保留程序化猫咪作为过渡方案，未宣称完成专业角色美术。 |

本地测试禁止复用未知预览服务；端口冲突可用 `MIAO_TEST_PORT` 指定独立端口，避免测到其他版本。

执行证据见 [验证状态](VALIDATION_STATUS.md)。真实设备、接收软件与安全软件的兼容性、非管理员权限流程及第三方 VRM 软件导入，继续按照审计报告的真机清单验收；不把模拟 IPC 或自动化测试当作这些实测。
