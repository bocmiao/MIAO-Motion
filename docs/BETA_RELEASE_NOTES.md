# 喵动 v0.3.0 测试版

新增原创猫咪“喵小动”、材质换色、语音嘴型、表情快捷键、自动画质和手动更新检查。角色加载会等待首帧，并显示“正在准备画面…”。下载与校验链接随公开版本更新。

新增实验功能：离线身体/手部追踪、OBS 自动配置、Windows 安装版原生虚拟摄像头、iFacialMocap 手机面捕。应用中的“新增功能图文教程”包含操作步骤与限制。

下载 `*-setup.exe` 安装，或全部解压 `MIAO-Motion-portable.zip` 后双击“**双击启动喵动.bat**”。无需 Node.js。原生摄像头和手机输入仅安装版支持；便携版可通过 OBS 输出。

每个安装包和 ZIP 都附同名 `.sha256`。使用 `Get-FileHash 文件路径 -Algorithm SHA256` 核对。暂无代码签名或国内镜像。

原生摄像头需在应用内手动安装组件并确认 Windows UAC；卸载喵动前先卸载组件。支持 64 位 DirectShow 接收端、640×360、最多 15 FPS、不带透明通道，不能保证所有会议软件可识别。轻捏人本版只做材质换色。身体/手部识别有遮挡、深度估计和性能限制；手机协议和物理设备仍待真机验收。

这是公开 beta，不是经过真实摄像头、手机、OBS 和普通用户完整验证的稳定版。浏览器便携版与桌面版的角色库独立。帧和模型不上传，麦克风只在本机分析音量；手机只传局域网动作参数。

原创猫咪资产条款随包附带。保留的 pixiv 官方技术示例使用独立 VRM 公共许可，不表示 pixiv 背书。反馈请附脱敏诊断，勿附私人模型、画面、推流密钥或账号凭据。
