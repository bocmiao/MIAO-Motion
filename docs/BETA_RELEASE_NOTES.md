# 喵动 Windows 测试版

这是公开测试版，不是经过真人/真实摄像头/OBS 全链路验证的稳定版。

下载 `*-setup.exe` 安装，或下载 `MIAO-Motion-portable.zip` 后全部解压，双击“**双击启动喵动.bat**”。无需安装 Node.js。便携版仅在本机 4173 端口提供服务。

每个安装包和 ZIP 都有同名 `.sha256`；使用 `Get-FileHash 文件路径 -Algorithm SHA256` 核对。当前未签名，若系统安全策略阻止，请不要关闭保护，可使用源码浏览器版或等待签名版。

本轮修复直播空白、透明底、取景、VRM 0.x 动作方向、眼神方向、模型存储/加载竞态；增加无角色跳过引导、角色制作教程、多平台指南和实际产物启动测试。

已知限制：无轻捏人、无身体/手部追踪、无原生虚拟摄像头；会议软件请用 OBS Virtual Camera。透明通道不能通过虚拟摄像头传递。国内镜像与代码签名尚未配置。浏览器便携版与 Tauri 桌面版不共享角色库，需分别导入原始 VRM；设置可导出导入。

包含 pixiv Inc. 官方技术示例角色（独立 VRM 公共许可 1.0，不是喵动原创或 MPL 资产），可一键离线体验；保留了原始文件、许可与出处，不表示 pixiv 背书。

摄像头与模型不上传。反馈请附应用生成的脱敏诊断，不要上传私人模型、画面、推流密钥或账号凭据。
