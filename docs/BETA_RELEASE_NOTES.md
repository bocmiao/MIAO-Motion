# 喵动 MIAO Motion v0.3.2-beta（测试版）

喵动是免费、本地运行的 VRM 角色动捕直播工具：用电脑摄像头让你的虚拟角色跟着你动，再接入 OBS、直播伴侣或会议软件。这是**测试版**，部分功能标为“实验”，可能在个别电脑或软件上不工作，欢迎反馈。

## 📥 下载哪个？（先看这里）

在本页最下方 **Assets** 里，普通用户**只需要下载一个文件**：

| 文件 | 给谁用 |
|---|---|
| **`MIAO.Motion_0.3.2_x64-setup.exe`（安装版，推荐）** | 大多数人选这个。双击安装，像普通软件一样从开始菜单打开；功能最全，包括虚拟摄像头和手机面捕 |
| `MIAO-Motion-portable.zip`（免安装版） | 电脑不让装软件（如公司、网吧电脑）时用。右键“全部解压缩”后双击“双击启动喵动.bat”，在浏览器里运行；没有虚拟摄像头和手机面捕 |
| 以 `.sha256` 结尾的两个文件 | 校验文件，用来确认下载完整。普通用户不用下载 |
| Source code (zip) / Source code (tar.gz) | 源代码，**不是程序**，下载了也不能直接用，不要下载 |

## ⚠️ 从 v0.3.0-beta 升级必读

**v0.3.0-beta 的虚拟摄像头组件存在安全隐患，请尽快升级到本版本。**

- **在 0.3.0 里装过“摄像头组件”的**：建议先打开 0.3.0，在“原生虚拟摄像头（Windows）”里点“卸载摄像头组件”，再安装 0.3.2。
- **来不及先卸载的**：直接安装 0.3.2 也可以，升级时会尝试把旧组件迁移到受保护目录。如果提示迁移失败，或启动时提示检测到旧版组件，请在“原生虚拟摄像头（Windows）”里点“卸载摄像头组件”清理，需要时再重新安装。
- **已经直接卸载了 0.3.0、会议软件里还残留“MIAO Motion Camera”的**：安装 0.3.2 后，在同一位置点“卸载摄像头组件”即可清理。
- **没装过摄像头组件的**：直接升级即可。

## 本版新增整改（第七、八轮）

- 安装版教程在程序内打开，外链使用系统浏览器；支持系统拖放和带主窗口的“另存为”。
- “创建我的角色”提供八步捏人和实时预览。“完成并使用这个角色”会保存到角色库，重启可恢复，重复保存更新同一条；“不保存，返回”恢复之前的角色，草稿保留。
- 从引导进入创建器后，完成会回到开摄像头步骤；“稍后再说”不再每次启动弹出。
- 虚拟摄像头改为 GPU 640×360 小画面与异步读回，调速计入 GPU 与发送等待，状态栏按真实发送间隔显示帧率。
- 修正中文部位名及重复名称、身体识别失败后的勾选和设置同步；头部比例烘焙进几何，骨骼保持单位缩放。
- 真实 iPhone、其他 VRM 软件、会议/直播软件兼容性仍需真机验收；程序化猫咪仍为过渡美术。

## 延续此前版本的修复

- 手机面捕：修复眨眼、微笑、视线不动的问题；连接时自动每 2 秒重发请求，5 秒没收到数据会提示你检查网络和防火墙。
- 身体/手部：修复手指一直不动；修复 VRM 0.x 角色四肢方向错误；身体识别改到后台运行，不再卡住画面。
- 镜像方向统一：开启“镜像动作”就像照镜子——你闭左眼、向左看、举左手、向左转头，角色都在你看来的左侧（角色自身的右侧）；关闭后角色用自身同侧。脸、眼神、头、身体和手都遵循同一规则。
- 虚拟摄像头组件改为安装到受保护的系统目录，修复 v0.3.0-beta 的安全隐患。卸载喵动时会自动注销组件；如果管理员确认点了“否”或没有管理员密码，可以选择继续卸载，残留组件不影响安全，之后可重装喵动清理或请管理员清理。
- 以后升级喵动时，已安装的摄像头组件会自动恢复（弹一次管理员确认）。
- OBS 自动配置：新场景名改为“喵动 · 绿幕角色”，失败时自动删除本次新建的内容，不留垃圾场景。
- 导出的 VRM 修复了格式校验错误。
- 窗口最小化后回来不再误报“画面准备超时”。
- 下载页的校验文件名与程序文件名一致，可以直接核对。

## 新功能

- **捏人**：原创猫咪“喵小动”可以换耳朵、尾巴、发型、衣服，起名、换色，并导出成 VRM 文件。导出的角色作者仍为喵动项目，适用 VRM 公共许可（可直播、商用、修改再分发）。其他 VRM 角色可以换色。
- **首页三个入口**：“用喵小动”“导入我的角色”“创建我的角色”，零基础也能马上开始。
- **平台向导**：主界面“我要接入”选择平台即显示步骤，覆盖 OBS、B站直播姬、抖音/快手直播伴侣、视频号、小红书、虎牙、斗鱼、腾讯会议/钉钉/飞书/Zoom/Teams 和推流码。
- 喵小动“生气”和“难过”表情不再一样。

| 窗口捕获接入 OBS/直播伴侣、自动配置 OBS | ✓ | ✓ |
| 原生虚拟摄像头 MIAO Motion Camera（实验） | ✗ | ✓ |

## 校验文件是否完整

每个文件都有同名的 `.sha256` 校验文件。在开始菜单搜索“PowerShell”打开，运行：

```powershell
Get-FileHash '下载文件的完整路径' -Algorithm SHA256
```

把显示的一长串字符与 `.sha256` 文件里的值逐字核对，完全一致才说明文件完整、没被改动。

## 关于“Windows 已保护你的电脑”

本测试版程序**没有数字签名**，运行时可能出现“Windows 已保护你的电脑”或“未知发布者”。请先按上面的方法核对校验值，确认一致后再选择继续运行。**不要为此关闭杀毒软件或智能应用控制。** 公司、学校电脑请遵守管理员规定。

## 已知限制

- 原生虚拟摄像头、手机面捕、身体/手部追踪都是实验功能，各会议和直播软件尚未逐个在真机上确认。
- 虚拟摄像头只有 64 位组件，固定 640×360、最多 15 帧/秒，没有透明背景；电脑较忙（例如没有独立显卡）时会自动降低输出帧率，减少对界面操作的影响，状态栏会显示实际帧率；32 位软件和 Windows“相机”等应用可能看不到它，可用 OBS 虚拟摄像头中转。安装和卸载组件需要管理员确认。
- 手机面捕需要付费 iOS App iFacialMocap（价格以 App Store 为准）和带 Face ID 的 iPhone/iPad，手机和电脑要在同一 Wi-Fi；安卓手机不支持，直接用电脑摄像头即可。
- 手机 App 不能直接选电脑上的虚拟摄像头，手机平台请用电脑端开播工具或推流码。
- 其他 VRM 角色只能换色，不能换部件。
- 暂无国内下载镜像和自动更新。
