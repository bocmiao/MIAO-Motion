# 第四轮整改候选说明（尚未发布）

main 在 v0.3.0 基线上修正手机表情通道、手指门控、VRM 0.x 四肢和身体镜像；身体与手部识别移至后台 Worker。旧 v0.3.0-beta 下载包不含这些修复。

原生虚拟摄像头改为受保护目录部署，卸载喵动时自动注销；管理员确认与安装结果在后台等待。输出仍为实验功能：仅 Windows 安装版、64 位 DirectShow、640×360、最多 15 FPS、无透明通道。会议和直播软件仍须逐个真机验证。

新增首页三入口、按平台接入向导，补小红书与直接选择 MIAO Motion Camera 的路线。新版喵小动可换耳朵、尾巴、发型和衣服，起名、换色并导出 VRM；其他角色仍只提供换色。原始作者与许可保留。

修正最小化后的首帧超时、OBS 失败残留、后续发布的校验文件名，并补齐 Rust 依赖许可。实际执行结果见 [验证状态](VALIDATION_STATUS.md)。

先体验角色和 OBS，推荐便携 ZIP；原生摄像头和局域网手机输入仅安装版。摄像头组件的安装/注销需要管理员，普通使用喵动不需要。暂无签名或国内镜像，不把自动化测试等同于真实设备或普通用户验收。

本文件是后续发行的候选说明。发布者应在最终 CI 通过、确认版本号与附件后，更新标题再发布；本轮没有覆盖旧 Release。
