# 直播与会议软件接入指南

> 核对日期：2026-09-28。各平台界面会更新，本页优先描述稳定的“窗口捕获”和“OBS 虚拟摄像头”路径。尚无真实 Windows 设备，本页菜单名和截图必须在 Gate A 中复核。

## 开播前统一准备

1. 在 MIAO Motion 导入 VRM、开启摄像头并完成正面校准。
2. 背景切到“绿幕”，点击“进入直播画面”。
3. MIAO Motion 窗口保持可见，不要最小化或被其他窗口完全遮挡。
4. 在目标软件中添加窗口捕获，选择 MIAO Motion 的浏览器窗口。
5. 开启色度键/绿幕抠图，取色为纯绿色；先录制 30 秒检查嘴型、左右方向和声音同步。

## OBS Studio（推荐基准路径）

1. “来源”区域点 `+`，添加“窗口捕获”。
2. 选择 MIAO Motion 窗口，裁剪浏览器边框。
3. 右键来源 → “滤镜” → 添加“色度键”，颜色类型选绿色。
4. 如果画面冻结，恢复 MIAO Motion 窗口并确保它未被完全遮挡。

“浏览器”来源仅为实验方案：OBS CEF 不共享 Chrome/Edge 的 IndexedDB，通常还需用 `--enable-media-stream` 启动 OBS。在 OBS 交互窗口内重新导入 VRM，并关闭普通页面的摄像头，避免摄像头被两处争用。

## 哔哩哔哩直播姬

在素材/来源区域寻找“窗口捕获”或同义入口，选择 MIAO Motion 窗口；若当前版本提供绿幕抠图，选择绿色。若没有色度键功能，先在 OBS 完成抠图和排版，再用 OBS 虚拟摄像头或平台允许的画面输入方式接入。

待真机补充：当前稳定版准确菜单名、截图、是否可直接色度键、窗口被遮挡时的行为。

## 抖音直播伴侣

官方帮助目前仍提供“添加直播画面 → 窗口”这一类窗口采集路径。选择 MIAO Motion 窗口后，按当前版本提供的绿幕抠图选项处理绿色背景；如窗口列表中没有目标，先让 MIAO Motion 窗口处于前台再刷新来源。

官方入口：<https://streamingtool.douyin.com/>；官方素材说明：<https://streamingtool.douyin.com/docs/guide/game>。

待真机补充：人物素材与窗口素材中哪一种保留动作最稳定、准确菜单截图、竖屏 9:16 的推荐布局。

## 快手直播伴侣

使用当前版本中的窗口/屏幕采集入口选择 MIAO Motion，再使用绿幕抠图。若软件只提供整屏采集，把 MIAO Motion 放到单独显示器或固定区域，并裁剪到角色画面。

待真机补充：官方下载页、当前稳定版准确菜单名、色度键能力与竖屏布局。未核实前不在本文写死按钮名称。

## 腾讯会议及其他会议软件

MIAO Motion 当前没有原生虚拟摄像头。通用过渡路径是：

1. 在 OBS 中按本页第一节捕获并抠出角色。
2. 在 OBS 点击“启动虚拟摄像机”。
3. 在会议软件的视频设置中选择 `OBS Virtual Camera`。
4. 先进入测试会议，确认预览方向、画幅和麦克风来源。

如果腾讯会议提示摄像头异常，先到 Windows“设置 → 隐私和安全性 → 摄像头”确认权限，再重新插拔/切换设备。腾讯会议官方权限说明：<https://meeting.tencent.com/support/topic/2103/index.html>。

## 已知边界

- 没有真实设备证据前，本页不宣称任何平台“已通过”。
- 浏览器窗口最小化或完全遮挡可能触发 Chromium 节流，使角色停止更新。
- 同一摄像头被 MIAO Motion、OBS 浏览器源、会议软件同时打开时，部分驱动会拒绝第二个请求。
- 平台版本、账号权限、直播资质和菜单可能不同；先做本地录制或测试会议。
