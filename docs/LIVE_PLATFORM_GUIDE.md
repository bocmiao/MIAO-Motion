# 直播与会议软件接入指南

> 适用版本：喵动 v0.3.1-beta（测试版）。核对日期：2026-09-29。
>
> 各平台客户端经常改版，本页写的菜单位置是“通常在哪里”，**以你电脑上当前版本为准**。能否开播、能否使用推流码取决于平台对你账号的规定，喵动不能代办或绕过。本页与程序内的 [按平台接入页](../public/platforms.html) 以及主界面“我要接入”下拉框的步骤一致。

## 先看：三条通用路线

不管用哪个平台，都是下面三条路线之一。看不懂时，先用路线 ①。

| 路线 | 适用 | 优点 | 限制 |
|---|---|---|---|
| ① 窗口捕获 + 抠绿幕 | 便携版、安装版都能用；几乎所有电脑直播软件 | 最稳，分辨率跟随窗口，横竖屏都行 | 喵动窗口不能最小化或被完全挡住 |
| ② 原生虚拟摄像头“MIAO Motion Camera” | 仅 Windows 安装版；能选摄像头的 64 位电脑软件 | 像普通摄像头一样选择，窗口可以放后面 | 实验功能；固定 640×360、最多 15 帧/秒、没有透明背景；安装组件需要管理员确认 |
| ③ OBS 推流码 | 平台给你的账号提供了“推流地址 + 推流密钥” | 画面、分辨率完全由 OBS 控制 | 需要平台开通推流权限；密钥不能泄露 |

**手机 App 不能直接选电脑上的虚拟摄像头。** 想在抖音、快手、视频号、小红书等手机 App 里开播时，请改用这些平台的**电脑端**开播工具，或平台提供的推流码（路线 ③）。

### 开播前统一准备（三条路线都要做）

1. 在喵动选好角色（可用喵小动），开启摄像头，正对镜头点“正面校准”。
2. 左右转头、眨眼、举手，确认方向符合你的习惯（见文末“镜像方向”）。
3. 横屏直播在“输出比例”选 16:9；竖屏直播选 9:16。
4. 麦克风要在直播/会议软件里单独选择。喵动的“语音嘴型”只用声音驱动嘴巴，不会把声音传给直播软件。
5. 正式开播前先录制 30 秒或开一场测试会议，检查画面、嘴型和声音。

### 路线 ①：窗口捕获 + 抠绿幕

1. 在喵动把背景切到“绿幕”，点“进入直播画面”（按 Esc 或双击画面可返回）。
2. 在直播软件里添加“窗口捕获”（有的软件叫“窗口”“窗口采集”“添加素材 → 窗口”），选择喵动的窗口。
3. 添加“色度键”或“绿幕抠图”，颜色选绿色。软件没有抠图功能时，可以先在 OBS 抠好，再用路线 ② 或 ③。
4. 喵动窗口保持可见，不要最小化，也不要被其他窗口完全盖住；否则画面可能停住。单屏电脑可以把喵动和直播软件左右并排。
5. 画面黑屏时，先确认喵动没有最小化；在 OBS 里可以在窗口捕获属性中换一种“捕获方式”再试（各版本名称可能不同）。

### 路线 ②：原生虚拟摄像头 MIAO Motion Camera（安装版，实验）

1. 使用 Windows 安装版，先让角色出现在画面中。
2. 展开“原生虚拟摄像头（Windows）”，第一次使用点“安装摄像头组件”，在 Windows 管理员确认中点“是”。
3. 点“开始虚拟摄像头输出”。**一定要先开始输出，再去接收软件里选择摄像头**。
4. 在直播或会议软件的摄像头列表里选择 **MIAO Motion Camera**。列表里没有或画面不动时，在接收软件里重新选择一次摄像头，或关掉接收软件重新打开。
5. 输出为 640×360、最多 15 帧/秒，只有角色画面，**没有透明背景**。需要抠像时，保持喵动绿幕背景，在接收软件里抠绿色。

说明：

- 组件是 64 位 DirectShow 摄像头，存放在受保护的 Program Files 目录。部分 32 位软件、Windows 自带“相机”等 UWP 应用可能看不到它，这时请用路线 ① 或 OBS 中转（见“腾讯会议等会议软件”）。
- 安装和卸载组件需要管理员确认；平时开始/停止输出不需要。公司、学校电脑请按管理员规定使用。
- 卸载喵动时会请求管理员确认来注销组件。如果点了“否”或没有管理员密码，程序会询问是否仍然卸载喵动：可以继续卸载，组件会留在受保护目录，不影响安全；以后可重新安装喵动，在“卸载摄像头组件”里清理，或请管理员清理。其他 Windows 用户安装的组件不会阻止你卸载。
- 从 v0.3.1-beta 起，升级喵动会自动恢复已安装的组件（会弹一次管理员确认）。**v0.3.0-beta 的组件存在安全隐患**：从 v0.3.0-beta 升级时程序会把旧组件迁移到受保护目录；如果提示迁移失败或检测到旧版组件，请在“原生虚拟摄像头（Windows）”里点“卸载摄像头组件”清理。

### 路线 ③：OBS 推流码

1. 在平台的开播后台或电脑开播工具里查找“推流”“第三方推流”“OBS 推流”一类入口（名称和位置以平台当前版本为准），获取“服务器/推流地址”和“推流密钥/串流码”。没有这个入口，说明账号暂未开通，喵动无法绕过。
2. 在 OBS 用路线 ① 把喵动加进场景（也可以用喵动的“自动配置 OBS”一键创建，见下文）。
3. OBS“设置 → 直播”：服务选“自定义”（或平台名称，如果列表中有），分别填入服务器地址和推流密钥。
4. 先在 OBS 里预览或录制检查，再点“开始直播”。部分平台还需要在网页或 App 里再点一次“开始直播”。
5. 推流密钥相当于开播密码：不要截图、不要发群、不要发给别人。喵动不会读取或保存它，也不会替你开始推流。

## 竖屏直播：OBS 画布设为 1080×1920

抖音、快手、视频号、小红书等常用竖屏。用 OBS 时这样设置：

1. OBS → “设置” → “视频”。
2. “基础（画布）分辨率”手动输入 `1080x1920`；“输出（缩放）分辨率”也填 `1080x1920`；帧率一般选 30。
3. 点“确定”，预览区会变成竖长方形。
4. 喵动“输出比例”选“竖屏 9:16”，取景选“半身”或“头像”。
5. 用路线 ① 捕获喵动窗口，拖动红框让角色填满画面；上下留出平台字幕、评论和按钮的位置。
6. 横屏直播改回 `1920x1080`。经常切换时，可在 OBS 用“配置文件”分别保存横屏和竖屏设置。

直播伴侣类软件一般有“横屏/竖屏”切换，直接切换即可，以软件当前界面为准。原生虚拟摄像头固定输出横向 640×360，放进竖屏会上下留边、画面较小，**竖屏优先用窗口捕获**。

## OBS Studio（推荐基准）

1. OBS “来源”区域点 `+`，添加“窗口捕获”，选择喵动窗口，必要时裁掉边框。
2. 右键来源 → “滤镜” → 添加“色度键”，颜色类型选绿色。
3. 也可以用喵动的“自动配置 OBS”：在 OBS“工具 → WebSocket 服务器设置”里启用服务器（端口 4455）并复制密码；回到喵动展开“自动配置 OBS（Windows）”，填入密码后点“创建绿幕场景”。喵动会新建一个名为“喵动 · 绿幕角色”的场景（重名时自动加序号），包含窗口捕获和绿色抠像；不会修改你原有的场景，也不会开始推流。中途失败会删除本次新建的内容；如果是连接中断导致无法清理，会列出需要你手动删除的场景名。
4. 调整角色大小、背景和麦克风，录一段检查后再开播，或按路线 ③ 推流。

“浏览器”来源只是进阶实验：OBS 内置浏览器不共享你在普通浏览器里导入的角色，通常还要用 `--enable-media-stream` 参数启动 OBS，并在 OBS 的“交互”窗口里重新导入角色。新手请用窗口捕获。

## 哔哩哔哩直播姬

- **推荐**：路线 ① —— 在直播姬的素材/来源区域添加窗口类素材，选择喵动窗口；如果当前版本提供绿幕抠图，颜色选绿色。
- **安装版可试**：路线 ② —— 添加摄像头类素材，选择 MIAO Motion Camera。
- **有推流权限时**：路线 ③ —— B 站通常在网页端直播中心提供推流地址和密钥（以当前页面为准），可用 OBS 推流。
- 横竖屏以直播姬当前的开播设置为准。

## 抖音直播伴侣

- 官方入口：<https://streamingtool.douyin.com/>。
- **推荐**：路线 ① —— 官方帮助中提供“添加直播画面 → 窗口”这类窗口采集方式，选择喵动窗口后使用绿幕抠图选项。窗口列表里找不到喵动时，先把喵动窗口切到前台再刷新。
- **安装版可试**：路线 ② —— 添加摄像头类画面，选择 MIAO Motion Camera。
- 竖屏直播先在直播伴侣里切到竖屏，喵动选 9:16。
- 抖音是否给你的账号开放第三方推流（路线 ③）以平台规定为准。

## 快手直播伴侣

- **推荐**：路线 ① —— 使用当前版本的窗口/屏幕采集入口选择喵动，再使用绿幕抠图。若只能采集整个屏幕，把喵动放在固定位置或第二块屏幕，再裁剪到角色区域。
- **安装版可试**：路线 ② —— 摄像头来源选择 MIAO Motion Camera。
- 竖屏以直播伴侣的横竖屏设置为准；账号若开通推流权限，也可用路线 ③。

## 视频号（竖屏）

微信视频号的电脑端开播，一般通过网页“视频号助手”（<https://channels.weixin.qq.com/>）的直播功能获取推流信息，再用 OBS 推流；具体菜单以当前页面为准。

1. OBS 按上文“竖屏直播”把画布设为 1080×1920，喵动选 9:16。
2. 用路线 ① 把喵动加入 OBS 场景（或用“自动配置 OBS”）。
3. 在视频号助手的直播页面找到推流地址和密钥，按路线 ③ 填入 OBS。
4. OBS 开始推流后，回到视频号助手页面确认画面正常，再按页面提示开始直播。

手机微信里直接开播时无法选择电脑的虚拟摄像头。视频号直播资格、推流是否可用以微信官方规则为准。

## 小红书

1. 先在小红书官方开播入口确认你的账号能否使用电脑开播工具或推流（以官方当前提供的入口为准）。
2. 电脑工具如果提供“窗口”来源，用路线 ①；如果提供“摄像头”来源，安装版可试路线 ②。
3. 获得官方推流地址和密钥后，用路线 ③；竖屏按上文设置 1080×1920。
4. 手机小红书 App 不能直接选择电脑上的虚拟摄像头。

小红书电脑端的实际兼容性尚未在真机上验证。

## 虎牙直播

- 虎牙的电脑开播工具通常支持添加窗口和摄像头类素材（名称以当前版本为准）。
- **推荐**：路线 ① 窗口捕获 + 绿幕抠图；**安装版可试**：路线 ② 选择 MIAO Motion Camera。
- 账号提供推流码时，也可用路线 ③ 由 OBS 推流。

## 斗鱼直播

- 斗鱼的电脑开播工具通常支持添加窗口和摄像头类素材（名称以当前版本为准）。
- **推荐**：路线 ① 窗口捕获 + 绿幕抠图；**安装版可试**：路线 ② 选择 MIAO Motion Camera。
- 账号提供推流码时，也可用路线 ③ 由 OBS 推流。

## 腾讯会议、钉钉、飞书、Zoom、Teams 等会议软件

会议软件一般只能选“摄像头”，不能窗口捕获，所以用下面两种方法之一：

**方法 A（安装版，实验）**：喵动点“开始虚拟摄像头输出” → 在会议软件的视频/摄像头设置里选择 **MIAO Motion Camera**。看不到时，在会议软件里重新选择摄像头或重开会议软件。

**方法 B（便携版，或方法 A 不识别时）**：

1. 在 OBS 用路线 ① 捕获喵动；如果抠掉了绿幕，在角色下面放一张背景图（虚拟摄像头不传透明，抠空的地方会变成黑色或其他颜色）。
2. OBS 点“启动虚拟摄像机”。
3. 会议软件的摄像头选择 `OBS Virtual Camera`。

注意：

- 麦克风在会议软件里单独选择。
- 会议软件的**本地预览**常常会把自己镜像显示，对方看到的方向可能与你预览里的不同。先请同事或用第二个账号看一下，再决定是否调整喵动的镜像设置。
- 会议软件提示摄像头异常时，先到 Windows“设置 → 隐私和安全性 → 摄像头”确认允许桌面应用使用摄像头，再重新选择设备。腾讯会议官方权限说明：<https://meeting.tencent.com/support/topic/2103/index.html>。
- 同一个实体摄像头被喵动、OBS 浏览器来源、会议软件同时打开时，部分驱动会拒绝后开的程序。让喵动独占实体摄像头，其他软件使用 MIAO Motion Camera 或 OBS Virtual Camera。

## 镜像方向

喵动默认开启“镜像动作”，效果就像照镜子：你闭左眼、向左看、举左手、向左转头，角色都在**你看来的左侧**动（也就是角色自身的右侧）。关闭镜像后，角色用自身的同侧（你举左手，角色举它自己的左手，在你看来在右边）。上下方向不受影响。设置位置：“高级设置与模型诊断 → 动捕设置 → 镜像动作”。

## 已知边界

- 原生虚拟摄像头、手机面捕、身体/手部追踪都是实验功能。会议和直播客户端的兼容性尚未逐个在真机上确认，本页不宣称任何平台“已通过”。
- 喵动窗口最小化或被完全遮挡时，画面可能停止更新。
- 平台版本、账号权限、直播资质和菜单可能不同；先做本地录制或测试会议。
- 不要使用第三方工具绕过平台对账号的开播或推流限制。
